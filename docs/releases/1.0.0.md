## Что нового

Первая версия для рабочего контура банка. Портал ИБ работает на закрытом хосте без интернета и внешних интеграций: конструктор реестров (уязвимости с импортом отчёта сканера и сроками по п. 7.1–7.4, риски ИБ с решениями ОУР, устройства DLP, разрешения на доступ с PDF, инциденты, свои реестры), импорт и экспорт Excel, автоматизации «условие → действие» с задачами, доска задач и «Почта → задача» вставкой текста, документы с маршрутом согласования и итоговым PDF, доказательная база с формами по шаблонам и просмотром файлов, глобальный поиск (в том числе по тексту PDF), дашборд и экран настенного монитора, пользователи и роли (RBAC), журнал аудита.

**Установка — с нуля** по `docs/deploy.md` в архиве. Обязательные переменные `.env`: пароли БД, `SESSION_SECRET`, **`PORTAL_URL`** (адрес портала; без него backend не стартует), подсети `FRONT_SUBNET`/`BACK_SUBNET`, согласованные с сетевым отделом. Рекомендуется задать `ADMIN_ALLOWED_IPS` (рабочие места администраторов — вместо MFA, ADR-0015), для настенных мониторов — `MONITOR_ALLOWED_IPS`, для документов — `ONLYOFFICE_URL_PREFIX`.

**Проверено перед выпуском:** e2e (51 сценарий) на образах релиза через nginx; заголовки безопасности и TLS 1.2/1.3; образы без исходников и dev-зависимостей, процессы не от root; резервная копия, ротация и восстановление в отдельном проекте; нагрузка — 20 000 уязвимостей, 5 000 задач, 2 000 устройств, 1 000 разрешений с PDF: экраны и поиск до 0,5 с, zip-выгрузка — около 1 с.

**Известные ограничения:** выгрузка Excel 20 000 записей — 5–6 с (ускорение в 1.0.1); 4 уязвимости high во вспомогательных зависимостях Prisma CLI не эксплуатируются, риск принят, обновление в 1.0.1 (ADR-0014); MFA не делается (ADR-0006 отклонён).

Полный список изменений — `CHANGELOG.md` в этом архиве.

Если портала на сервере ещё нет — по `docs/deploy.md`, разделы 1–9 (требования к серверу, тома, `.env`, сертификат, первый администратор, монитор, резервные копии, проверка). Разделы «Выкладка» и «Откат» ниже — для обновления.

## Выкладка (обновление)

Все команды — на сервере. Для журнала выкладок запишите дату, версию, своё имя, имя резервной копии (шаг 3) и результат и передайте разработчику.

```bash
# 1. Проверить архив, распаковать, проверить файлы
cd /srv/ibportal/releases
sha256sum -c ibportal-1.0.0.tar.gz.sha256
tar -xzf ibportal-1.0.0.tar.gz && cd ibportal-1.0.0 && sha256sum -c SHA256SUMS

# 2. Загрузить образы
docker load -i ibportal-images-1.0.0.tar.gz

# 3. Резервная копия (ОБЯЗАТЕЛЬНО). Если копия не создалась — стоп
cd /srv/ibportal/deploy
./scripts/smoke.sh --before
./scripts/backup.sh               # имя копии — в журнал выкладок

# 4. Обновить compose и скрипты (.env и certs не трогаются); новые переменные из раздела выше — в .env
cp /srv/ibportal/releases/ibportal-1.0.0/docker-compose*.yml .
cp /srv/ibportal/releases/ibportal-1.0.0/scripts/*.sh scripts/

# 5. Новая версия, миграции, перезапуск backend и frontend (db не перезапускается)
sed -i 's/^VERSION=.*/VERSION=1.0.0/' .env
docker compose --profile tools run --rm migrate
docker compose up -d backend frontend

# 6. Проверка
./scripts/smoke.sh --after
```

## Откат

Миграции совместимы с прошлой версией — вернуть её:

```bash
cd /srv/ibportal/deploy
sed -i 's/^VERSION=.*/VERSION=нет (первая установка)/' .env
docker compose up -d backend frontend
./scripts/smoke.sh
```

Если релиз испортил данные — `./scripts/restore.sh <копия из шага 3>`: проверит контрольные суммы, спросит подтверждение, сделает копию текущего состояния, восстановит и проверит целостность. Не пройдена — сервисы не поднимать, связаться с разработчиком. Затем прежний `VERSION`, `docker compose up -d backend frontend`, `./scripts/smoke.sh`. Образы прошлой версии не удалять хотя бы неделю.

## Что проверить после выкладки

- [ ] `smoke.sh` — «Smoke-проверка пройдена», число записей не уменьшилось.
- [ ] `docker compose ps`: `db` и `backend` — `healthy`, `frontend` — `running`.
- [ ] Портал открывается по `PORTAL_URL`, вход работает, меню соответствует правам.
- [ ] `docker compose logs --since 10m backend migrate` — без ошибок и попыток обратиться в интернет.
- [ ] Данные для журнала выкладок переданы разработчику.

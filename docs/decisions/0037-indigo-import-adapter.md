# ADR-0037. Адаптер отчётов INDIGO

Дата: 05.11.2026. Статус: принято (релиз 1.8.0; план — `docs/plans/release-1.8.0.md`, спецификация — `docs/specs/awareness.md`, раздел 4).

## Контекст

Результаты тестирования сотрудников на платформе INDIGO выгружаются отчётом «Статистика по баллам». Формат известен по описанию, реального файла в репозитории нет, и данные в нём — данные банка. Отчёт приходит как двоичный `.xls` (BIFF8), часто с повреждённым хвостом. Колонки сдвигаются, между тройками «Б, М, %» бывают пустые колонки, сводка стоит над таблицей.

Импорт реестров уже умеет предпросмотр, применение одной транзакцией и проверку версий. Адаптеры KSC и реестра сервисов (ADR-0032) превращают чужой файл в лист этого конвейера.

## Решение

- **Свой конвейер не заводится.** Адаптер `?adapter=indigo` (`modules/awareness/import.ts`) готовит лист с колонками по названиям полей «Результатов INDIGO» и сведения для предпросмотра. Право — `records.edit`, как у остальных адаптеров. Только реестр `awareness_results`, иначе 409 `WRONG_ADAPTER`.
- **`.xls` не читается** (решение владельца 2). Тип файла определяется по содержимому: OLE — 400 `OLD_EXCEL_FORMAT` «Откройте его в Excel и сохраните как .xlsx». SheetJS не подключаем, своего разбора BIFF8 нет. `.xlsx` и SpreadsheetML читает общий `readSheets`.
- **Всё ищется по текстам** (`indigo.ts`):
    - лист «Статистика по баллам»; если лист один — он же;
    - тест — первая непустая ячейка строки 1;
    - строка заголовков — по «№» и «Фамилия»;
    - тройки «Б, М, %» — слева направо, пустые колонки пропускаются;
    - сводка — по меткам строк. Числа относятся к группам по строке подписей «Обычные вопросы» / «Мультивыбор вопросы», а без неё — слева направо.

  Ошибка формата называет, чего не нашлось.
- **Строки листа конвейера — под номерами строк отчёта.** Ошибки конвейера и разбора называют строку отчёта. Строка с ошибкой (дата, процент, ФИО) не загружается, остальные загружаются.
- **Полнота**: строки × МаксБалл итога = Всего итога. Расхождение — предупреждение, импорт не блокируется: лимит выгрузки INDIGO неизвестен. Средний процент сводки показывается рядом со средним по строкам.
- **Повторы в один день** (решение 3): ключ попытки «тест | ФИО | дата». В лист попадает попытка с большим «Результатом, %», при равном — первая по порядку. Остальные — блок «Повторы в один день».
- **Оценка и «На пересдачу»** — по порогам `app_settings` `awareness.grades` на момент загрузки, с порогом пересдачи отдельно. Если у существующей записи процент тот же, адаптер подставляет прежние оценку и «На пересдачу». Так повторная загрузка ничего не меняет, а новые пороги действуют на новые загрузки.
- **«Нет в файле» не считается**: каждый отчёт — попытки за свой период.
- **Сведения** — `register_imports.summary.source`:
    - тест, число строк, ошибки, сводка;
    - полнота;
    - сколько сопоставлено автоматически и сколько требует выбора;
    - повторы.

  Сколько строк получили ручной выбор — `summary.choicesApplied` и сводная запись журнала при применении.

## Последствия

- Конвейер получил общие расширения (`docs/specs/awareness.md`, раздел 7):
    - выбор связи в предпросмотре (`ImportAdapter.choices`, `applyImport(..., { choices })`);
    - производные значения и предупреждения по `systemKey`.
- Адаптер полностью покрыт тестами на сгенерированных отчётах (`src/test/awareness-files.ts`). Первая загрузка настоящего отчёта — у владельца. Если формат окажется другим, ошибки назовут, чего не нашлось.
- Сопоставление с сотрудниками — ADR-0038.

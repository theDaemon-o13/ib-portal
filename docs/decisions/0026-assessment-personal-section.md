# ADR-0026. Личный раздел: право вне других ролей, задачи без обратной ссылки

Дата: 30.10.2026. Статус: принято (релиз 1.3.0, этап Д, решения владельца 30.10.2026).

## Контекст
Самооценка уровня кибербезопасности — личная работа одного человека; другие пользователи портала её не видят, утверждения нет. При этом по слабым местам нужны задачи на общей доске, а журнал аудита и история показывают действия многим.

## Решение
- **Одно право** `assessment.manage` на весь раздел и все маршруты `/api/v1/assessments`; не зависит от `ib.work`. Системная роль «Самооценка» с этим правом, seed никому её не назначает.
- **Право не распространяется**: выдать `assessment.manage` любой роли, кроме системной «Самооценка», нельзя — backend отвечает 409, в матрице ячейка заблокирована; снять его с роли «Самооценка» тоже нельзя. В «Супер-администратора» оно не входит; `check-integrity` проверяет, что право есть только у этой роли.
- **Журнал**: записи с сущностями `assessment*` в разделе «Журнал» (и его выгрузке) видят только держатели `assessment.manage` — фильтр в запросе журнала. Текст комментариев к ответам в `audit_log` не пишется («комментарий изменён»), баллы и целевые уровни — как есть. История раздела видна держателю права без `history.view` (это его данные).
- **Задачи по разрывам** ставит раздел: право — `assessment.manage` (`tasks.assign` не проверяется), исполнитель — активный сотрудник с `ib.work`, список исполнителей — маршрут раздела (только id и имя), принимают по правилам ADR-0022. Источник задачи `manual`, категорию выбирает владелец из существующих; название по умолчанию — название раздела без кода и баллов. В карточке задачи и её журнале нет ни раздела, ни баллов; связь — только `assessment_links`, видна внутри раздела. Форма предупреждает: «Задача будет видна всем на доске „Задачи“».
- **Удаления нет**: оценка уходит только в архив.
- **Напоминание о переоценке** — уведомлением ADR-0023 всем активным держателям права; ссылка на раздел — по виду уведомления.
- Виджетов на дашборде и мониторинге нет, глобальный поиск оценки не находит.

## Последствия
- Организационное правило «один человек» портал не проверяет: роль можно назначить нескольким пользователям, но не «размножить» через другие роли.
- Начальник ИБ с `audit.view` не видит записей журнала по самооценке, если у него нет права раздела.

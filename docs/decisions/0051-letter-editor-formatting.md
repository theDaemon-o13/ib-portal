# ADR-0051. Оформление текста письма: правила в одном месте, свои расширения редактора, избранное в браузере

Дата: 12.11.2026. Статус: принято (релиз 1.13.11; задание — `docs/tasks/1.13.11-letter-editor-formatting.md`, план — `docs/plans/release-1.13.11.md`). Дополняет ADR-0039 и ADR-0044.

## Контекст

Памятки по осведомлённости нельзя было оформить в портале: не было шрифта Times New Roman, цвета и фона текста, выравнивания, положения картинки, ширины столбцов и заливки. Письмо доделывали в Outlook руками. Санитайзер не пропускал `style`. В сборке — TipTap 3.32.0 без расширений цвета, шрифта и выравнивания; новые npm-пакеты не добавляются без согласия владельца.

## Решение

- **Один источник правил** — `backend/src/lib/letter-format.ts`: разрешённые теги, свойства `style` и их значения, шрифты, стандартные цвета, пределы ширины. Разбор `style` — по объявлениям. Frontend получает те же константы сгенерированным файлом. Проверяет всегда backend при сохранении, результат — канонический вид.
- **Строгий белый список значений:** цвета только `#RRGGBB`, шрифт только Times New Roman (Arial — по умолчанию), четыре выравнивания, пять положений картинки, ширина картинки 40–544 px, ширина столбца 10–100 %. Всё остальное, включая `rgb()`, `!important`, `url()`, удаляется. Редактор перед отправкой приводит стили к этому виду сам: браузер сериализует цвета как `rgb(…)`.
- **Свои расширения TipTap на ядре** вместо пакетов text-style, color, highlight, font-family, text-align и column resize: метка `letterStyle` (шрифт, цвет, фон в одном `span`), атрибуты у underline, абзацев, картинки и ячеек, перетаскивание границы столбца. Палитра — свой компонент. Новых зависимостей нет.
- **Выгрузка — почтовая вёрстка:** встроенные стили и атрибуты `align`, `bgcolor`, `width`, `hspace`/`vspace`, без `float`, `div` и классов.
    - Цветное подчёркивание — `text-decoration-color`. Outlook классический рисует его цветом текста. `border-bottom` у `span` отвергнут: движок Word сдвигает интервал.
    - Фон текста — `background-color` у `span`. `mso-highlight` знает только 16 цветов.
- **Избранные цвета — `localStorage` с ключом по id пользователя**, два набора (текст; фон), до 12. Серверного хранилища личных настроек интерфейса без миграции нет; это состояние интерфейса (CLAUDE.md, раздел 2). Серверный вариант — отдельным решением: `user_ui_settings` и `GET/PUT /me/ui-settings/:key` с теми же проверками.

## Последствия

- Схема БД, отправленные письма и их снимки не меняются. Содержимое без новых атрибутов выгружается байт в байт как в 1.13.10.
- Избранное привязано к браузеру: на другом компьютере его собирают заново.
- В карточке шаблона и письма (панель около 660 px) панель редактора занимает две строки.
- Проверить вид в почтовых клиентах (Outlook классический, новый Outlook, WorldClient) из среды разработки нельзя. Для этого — чек-лист в руководстве и шаг «Вручную» в сообщении для DevOps.

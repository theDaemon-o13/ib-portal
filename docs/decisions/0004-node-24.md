# ADR-0004. Node.js 24 LTS вместо 20

Дата: 2026-10-26. Статус: принято (согласовано с владельцем проекта).

## Контекст
CLAUDE.md задавал Node.js 20 LTS. Поддержка Node 20 закончилась 30.04.2026: исправления безопасности больше не выходят.

## Решение
Backend, сборка frontend и dev-окружение используют Node.js 24 LTS (поддержка до апреля 2028). Базовый образ закреплён по тегу и digest (`node:24.22.1-alpine3.24@sha256:…`) в Dockerfile; `engines` в `package.json` — `>=24 <25`.

## Последствия
- Переход на следующую LTS — отдельным ADR и релизом.
- Машина сборки должна иметь Node 24 для локальной разработки и тестов.

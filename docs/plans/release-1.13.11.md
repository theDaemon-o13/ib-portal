# План релиза 1.13.11 — Осведомлённость: оформление в редакторе письма

Задание: `docs/tasks/1.13.11-letter-editor-formatting.md` (текст владельца от 11.11.2026). От `v1.13.10`. **Схема БД не меняется:** оформление — атрибуты в HTML письма (`awareness_letter_versions.html_*`, `awareness_templates`), его пропускает санитайзер. Миграций, новых переменных `.env`, прав и npm-зависимостей нет. Выкладка — замена backend и frontend без `migrate`, откат на 1.13.10 — образы.

Решения «выбрано по умолчанию» помечены ★ — для отчёта.

## 0. Что есть сейчас

- Редактор — TipTap 3.32.0: `@tiptap/core`, `react`, `starter-kit` (в нём underline, link, списки), `extension-image`, `extension-table` (TableKit, `resizable: false`). **Нет** text-style, color, highlight, font-family, text-align — пишем свои расширения на ядре (метка и глобальные атрибуты), без новых пакетов.
- Плавающая панель картинки — `BubbleMenu` из `@tiptap/react/menus`: подпуть уже установленного `@tiptap/react` 3.32.0, его зависимости (`@tiptap/extension-bubble-menu`, `@floating-ui/dom`) уже в lockfile. Новой зависимости нет.
- Санитайзер (`awareness-letters/sanitize.ts`, sanitize-html) не пропускает `style`. Выгрузка (`export/content.ts`) — разбор токенами без DOM, атрибуты в двойных кавычках.
- **Личных настроек интерфейса на сервере без изменения схемы нет:** раскладка дашборда — своя таблица `dashboard_layouts`, `app_settings` — общие параметры портала. ★ Избранные цвета — `localStorage` браузера, ключ по id пользователя: у каждого своё, переживает выход и вход, но **привязано к браузеру**. Предложение отдельным пунктом (не в этом релизе): таблица `user_ui_settings (user_id, key, value jsonb, version)` и `GET/PUT /me/ui-settings/:key` с проверкой «только #RRGGBB, не больше 12, без повторов» — общая для избранного и других личных настроек.

## 1. Правила оформления — один источник

`backend/src/lib/letter-format.ts`:
- шрифты: Arial (по умолчанию, без атрибута) и Times New Roman (`'Times New Roman', Times, serif`);
- стандартные цвета текста, фона текста, заливки ячейки (п. 3, 4, 8 задания), `FAVORITES_MAX = 12`;
- выравнивания `left|center|right|justify`; положения картинки `left|center|right|wrap-left|wrap-right`, ширина 40–544, с обтеканием — до 280; ширина столбца 10–100%;
- `parseStyle` — разбор `style` по объявлениям (свой маленький разборщик: кавычки, скобки, комментарии вырезаются), `normalizeHex`, `filterStyle(tag, style)`.

Frontend получает те же константы файлом `frontend/src/api/generated/letter-format.ts` (пишет `npm run openapi:export`, как список языков 1.13.7; тест backend сверяет файл).

## 2. Хранение в HTML

| Что | HTML |
|---|---|
| Шрифт | `<span style="font-family:'Times New Roman', Times, serif">` |
| Цвет и фон текста | `<span style="color:#RRGGBB;background-color:#RRGGBB">` (одна метка, свойства в одном span) |
| Подчёркивание | `<u>` — цветом текста; `<u style="text-decoration-color:#RRGGBB">` — цветное |
| Выравнивание | `style="text-align:center|right|justify"` у p, h2–h4, li; по левому краю — без атрибута |
| Картинка | `<img data-align="…" width="N">`, высота при смене ширины снимается — пропорции сохраняет браузер |
| Таблица | ширина — `width="NN%"` у ячеек первой строки; заливка — `style="background-color:#RRGGBB"` у td/th |

★ Заголовки: в редакторе это h2–h4 («Заголовок 1–3»), в задании — «h1–h3». Правило выравнивания — для h2–h4.

★ Ширина столбцов — в процентах прямо в HTML. Своё перетаскивание границы и поле «Ширина столбца, %»; встроенный `columnResizing` (ширина в px, `colwidth`) не используется, перевода px → % при выгрузке нет. Пересчёт: изменённый столбец получает новое значение, остальные — пропорционально прежним, минимум 10%, сумма 100%.

## 3. Санитайзер (backend, источник правды)

- `style` — только у span, u, p, h2–h4, li, td, th, только свойства и значения из п. 11 задания, после нормализации (регистр, пробелы, HEX — верхний регистр). Повтор свойства, `!important`, `url()`, `expression`, `var()`, комментарии, любое другое свойство — объявление удаляется; пустой `style` — атрибут удаляется.
- img: `data-align` из списка, `width` — целое 40–544 (старое правило «1–4 цифры» для width заменено), `height` — как раньше.
- td/th: `width` — «NN%», 10–100.
- Итоговый `style` — канонический вид (`prop:value;prop:value`), повторное сохранение его не меняет.

## 4. Выгрузка (`export/content.ts`)

- span: шрифт, цвет, фон — встроенным стилем внутри абзаца макета (Arial 15/23 абзаца не меняется).
- ★ Фон текста — `background-color` у span: Outlook классический (движок Word) показывает фон у span; `mso-highlight` знает только 16 именованных цветов и не передаёт свои цвета.
- ★ Подчёркивание цветом — `<u style="text-decoration:underline;text-decoration-color:#…">`: так в новом Outlook и WorldClient (браузерная вёрстка). Outlook классический рисует подчёркивание цветом текста — ограничение в руководстве. `border-bottom` у span не выбран: движок Word рисует рамку у строчных элементов непредсказуемо и сдвигает межстрочный интервал.
- Выравнивание — `align="…"` и `text-align` у p, h2–h4, li.
- Картинка: на отдельной строке — `<p align style="text-align">` с `<img width style="display:inline-block;max-width:100%;height:auto">`; с обтеканием — `<img align="left|right" width hspace="12" vspace="4" style="margin:…;max-width:45%;height:auto">`. ★ Отступ в Outlook классическом — `hspace`/`vspace` (он не применяет margin у картинки), в остальных — `margin` (встроенный стиль сильнее атрибута). ★ `max-width:45%` — встроенный: на компьютере картинка с обтеканием не шире ≈245 px из 544 даже при заданных 280 (в Outlook классическом — по `width`).
- Таблица с заданной шириной — `width="100%"`, у ячеек первой строки `width="NN%"`; заливка — `bgcolor` и `background-color` (заливка сильнее серого фона заголовка).
- Содержимое без новых атрибутов выгружается байт в байт как в 1.13.10 (снимок-тест).

## 5. Редактор (frontend)

- Расширения: `letterStyle` (метка span: шрифт, цвет, фон), атрибут `color` у underline, `textAlign` у paragraph/heading/listItem (Ctrl+L/E/R/J и Ctrl+Shift+…), `align` у image, `width` и `background` у ячеек, перетаскивание границы столбца.
- Палитра — свой компонент `ColorPalette` и кнопка с разделённым нажатием `ColorSplit`: последний цвет полосой, «Избранные», стандартные, «Свой цвет» (HEX с образцом и звёздочкой), «Без цвета»; клавиатура (стрелки, Enter, Esc, Delete), подписи «Красный, #DC2626, в избранном»; предупреждение «Текст будет плохо виден» при контрасте ниже 4,5:1 (фон текста, заливка).
- Избранное — `favorites.ts` (чистые функции + хранилище): два набора — «текст» (цвет текста, подчёркивание) и «фон» (фон текста, заливка).
- Панель: шрифт — `Select`; цвет текста, фон, подчёркивание — разделённые кнопки; выравнивание — одна кнопка с меню; «Очистить форматирование». При 1440 px — одна строка; на 375 px — перенос.
- Картинка: `BubbleMenu` — пять положений, ширина px, 25/50/75/100%, предупреждение «шире 280 px» с кнопкой «Уменьшить до 280».
- Таблица: «Ширина столбца, %», «Заливка ячейки» в меню таблицы.
- Лист редактора — всегда белый, текст #0F172A, и в чёрной теме; панель и рамка — в теме портала.
- Вставка (`paste-format.ts`): из стилей Word остаётся только разрешённое (п. 9), цвета — к HEX (rgb, #rgb, основные имена), чёрный и почти чёрный текст и белый фон снимаются; избранное не меняется.

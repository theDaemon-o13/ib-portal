# План 1.13.4 — элементы форм в стиле «Океан»

Задание — `docs/tasks/1.13.4-forms.md`. Только frontend: миграций, изменений API и npm-зависимостей нет. От `v1.13.3`, архив `--from 1.13.3`, откат — образ frontend 1.13.3.

## 1. Select

- Компонент `components/Select.tsx`, замена `<select>` → `<Select>` во всех 142 местах (54 файла) без изменения свойств и `<option>`.
- Внутри — **скрытый нативный `<select>`** со всеми прежними свойствами (`value`, `onChange`, `required`, `disabled`, `form`, `name`, `data-testid`): выбор в своём списке ставит значение и посылает настоящее событие `change`. Поэтому обработчики, валидация (`required`) и отправка форм не меняются; e2e-проверки, которые читают `.options` и `.value`, работают как раньше. *Выбрано по умолчанию* — вместо переписывания 131 обработчика.
- Видимая часть — `<button role="combobox" aria-haspopup="listbox">` перед нативным (клик по подписи `<label>` открывает список), список — `role="listbox"` в портале (`document.body`) поверх окон, открывается вверх, если внизу нет места; ширина — не уже поля и в пределах экрана.
- Клавиатура (WAI-ARIA APG, select-only combobox): закрыт — ↓ ↑ Enter Пробел Alt+↓ открывают, Home/End — первое/последнее, буквы — поиск по началу; открыт — ↑ ↓ PageUp/PageDown Home End, Enter/Пробел — выбрать, Esc и Tab — закрыть без изменения, буквы — к совпадению. Недоступные (`disabled`) пропускаются.
- Больше 15 значений — поле поиска в списке (без регистра, «ё» = «е»), фокус в нём, ↑ ↓ Enter работают. *Порог 15 — выбран по умолчанию.*
- Логика клавиатуры, поиска и размещения — чистые функции `components/select-logic.ts` с unit-тестами (в проекте нет jsdom и библиотек тестирования компонентов, новых зависимостей не добавляем).
- e2e: помощник `ui.select` открывает список щелчком по combobox и щёлкает пункт по значению (вместо установки значения setter'ом); прямую установку в `vulns.e2e.mjs` — на `ui.select`.

## 2. Чекбоксы и radio

Общий стиль `input[type=checkbox|radio]`: `appearance:none`, рамка из токенов, акцентная заливка с галочкой (SVG-маска) или точкой, `:indeterminate` — черта, `:disabled`, `:focus-visible`. Прежние `accent-color` (base.css 146, 150, 303) — убрать, размеры оставить.

## 3. Прочие поля

- Дата и время: `::-webkit-calendar-picker-indicator` читается в «Чёрном океане» (color-scheme dark + яркость), календарь — системный в цветах `color-scheme`.
- Файл: `::file-selector-button` — кнопка в стиле портала.
- number: стрелки в цвет темы (`color-scheme`), без светлого фона.
- textarea — тот же стиль поля, `resize: vertical`.
- Полосы прокрутки: `scrollbar-color` из токенов на корне, в «Чёрном океане» — тёмные.
- `color-scheme` уже на `<html>` (tokens.css) — портал и модальные окна внутри него наследуют.

## 4. Проверка

Обе темы, 1440 и 375 px, Chrome на macOS (Chrome DevTools раннера e2e). **Chrome и Edge на Windows на машине разработчика недоступны** — проверяются после выкладки по чек-листу в `1.13.4-devops.txt`; наложение карточки под Windows по той же причине не воспроизводится здесь — если останется после 1.13.3, нужен снимок.

# Задание 1.13.7 — диагностика входа настенного монитора, выбор языка перевода

Текст решений владельца (10.11.2026) после отчёта о входе учётной записи монитора и плана по языкам.

## Монитор

1. Диагноз принят: отказ по адресу (`MONITOR_ALLOWED_IPS`) отвечает так же, как неверный пароль; причина видна только в журнале аудита. Исправление настройки на проде — после ответа DevOps, отдельно от релиза.
2. Материалы для DevOps и их ответы — в `ops/` (в `.gitignore`): репозиторий публичный, в ответах внутренние адреса.
3. Улучшения диагностики — все четыре, плюс тесты на каждую причину отказа:
   - строка `warn` в лог backend при отказе во входе: причина, логин, IP;
   - предупреждение при старте backend, если `MONITOR_ALLOWED_IPS` пуста; строка с итоговыми списками адресов;
   - понятная подпись причины отказа в разделе «Журнал»;
   - предупреждение в карточке пользователя с ролью «Настенный монитор» (пустой список адресов, последний отказ по адресу).

   Условия:
   - пользователю по-прежнему 401 «Неверный логин или пароль», без различий;
   - в `warn` при `unknown_user` логин в маске — первые 2 символа и длина (в поле логина иногда вводят пароль); при остальных причинах — логин полностью;
   - пароль и его производные никогда не попадают в лог.
4. `deploy-log.md` не трогать.

## Языки перевода документа (этап 23 «Перевод»)

5. Язык выбирается из списка, без ручного ввода: Русский, Таджикский, Английский; коды `ru`, `tg`, `en`. Список — в коде (`lib/languages.ts`, метки RU / TJ / EN, псевдоним `tj → tg` для учебных писем), без справочника и миграции. Ключи `tj` в базе и API учебных писем не меняются. В `document_translations.language` пишется название; API принимает и отдаёт `code`.
6. Один язык — один раз: выбранные языки в списке недоступны. Старые строки со свободным текстом не удаляются и не меняются, показываются как есть. Сопоставление старых строк со списком — только при показе и проверке дубля, без записи в базу:
   - `ru`: русский, russian, ru, rus, рус;
   - `tg`: таджикский, tj, tg, тоҷикӣ, tajik;
   - `en`: английский, en, eng, english.
7. Правка языка у существующей строки — только выбором из списка. Старую строку со свободным текстом при открытии на правку не переписывать, пока язык явно не выбран заново.
8. Правила переходов не меняются: 23 → 24 — у каждого языка ссылка; «Утвердить» — Word каждого перевода.
9. Тесты: выбор языка, запрет дубля, отображение старых записей, e2e этапа «Перевод».

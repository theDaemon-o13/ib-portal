Релиз 1.13.4 «Элементы форм в стиле „Океан“». От v1.13.3, только frontend, без миграции и без новых npm-зависимостей. Режим как в docs/tasks/README.md: план в docs/plans/release-1.13.4.md и сразу продолжай, вопросы — по умолчанию с отметкой в отчёте; стоп только при необратимом. Положи этот текст в docs/tasks/1.13.4-forms.md первым коммитом.

Зачем. Стандартные элементы браузера не подчиняются теме портала: раскрытый <select> на Windows рисуется светлым с голубым выделением, чекбоксы и поля даты — системные. Нужно, чтобы формы выглядели как остальной портал в обеих темах.

1. Выпадающие списки. Свой компонент Select в стиле портала: стеклянная панель, токены темы, выделение акцентом, тень и скругления как у карточек.
   - Доступность обязательна: роли combobox/listbox по WAI-ARIA; клавиатура — стрелки, Enter, Esc, Home/End, ввод букв для поиска; видимый фокус; закрытие по клику вне и по Esc; не обрезается в модальных окнах и у края экрана (открывается вверх, если внизу нет места; рендер в портал поверх окна).
   - Поиск по вводу для длинных списков (больше ~15 значений).
   - Нативный <select> сейчас в 142 местах в 54 файлах. Переведи все; если где-то замена рискованна (например, внутри сторонней разметки) — оставь нативный, но со стилями option и color-scheme темы, и перечисли такие места в отчёте.
   - Значения, onChange и disabled ведут себя как раньше: формы, валидация и отправка не меняются.
2. Чекбоксы и переключатели (radio): appearance: none, акцентная заливка с галочкой или точкой, видимый фокус, состояния disabled и indeterminate; клик по подписи работает как раньше. Сейчас окраска задаётся только accent-color в base.css (146, 150, 303) — замени на общий стиль для всех.
3. Остальное в формах: поля даты и времени (значок и календарь читаются в «Чёрном океане»), выбор файла — кнопка в стиле портала, number без светлых стрелок, textarea, полосы прокрутки в «Чёрном океане». color-scheme уже переключается в tokens.css — проверь, что он стоит на корневом элементе и действует внутри модальных окон.
4. Проверка: обе темы; Chrome и Edge на Windows (основной парк отдела) и Chrome на macOS; 1440 и 375 px. Скриншоты открытых списков, чекбоксов, radio и полей даты в docs/design/ocean/screens/ (только вымышленные данные).
5. Тесты: unit на клавиатурную навигацию и выбор в Select; e2e, которые выбирали значения через нативный select, переведи на действия пользователя с новым компонентом (по роли и подписи), не ослабляя проверок. Быстрые проверки перед коммитом, полный e2e на ibportal_e2e перед тегом.
6. Выпуск: тег v1.13.4, архив --from 1.13.3, GitHub Release (проверка содержимого, обратная загрузка, sha256), deploy/verification/1.13.4-devops.txt — только замена frontend, откат на 1.13.3. Красное — стоп и отчёт.

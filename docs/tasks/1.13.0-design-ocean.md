Ограничения: без новых npm-зависимостей без моего согласия, без внешних ресурсов (портал в закрытом контуре: никаких Google Fonts и CDN), deploy/, тома, .env и сертификаты не трогать, ничего из раздела 3.1 CLAUDE.md без моего подтверждения.

Зачем. Текущий дизайн мне не нравится. Новый — стеклянный стиль «Океан»: глубокий сине-бирюзовый фон с мягкими световыми пятнами, плавающие матовые панели, синий Apple как акцент.

**Это релиз только frontend.** Никаких миграций, изменений API, прав и данных. Если для какого-то экрана без изменения backend не обойтись — вынеси в план вопросом, не делай.

## 0. Эталон

Лежит в репозитории, `docs/design/ocean/` (см. README.md там):
- `ocean.css` — токены обеих тем и компоненты (сайдбар, топбар, сцена, карточки, кнопки, сегменты, чипы, таблица, списки, столбчатая диаграмма, анимации, адаптив);
- `Main.dc.html` (дашборд, тема «Океан») и `Registers.dc.html` (реестр уязвимостей, тема «Чёрный океан») — макеты. Разметка в них шаблонная (`<x-dc>`, `sc-if`, `{{ }}`) — это не код для копирования, а образец вида, сетки и отступов;
- `signature/` — SVG подписи: полная, автограф, инициалы; файлы без суффикса — с `currentColor`.

Верстай по эталону, отклонения перечисли в плане. Данные в макетах вымышленные.

## 1. Темы

- Две темы: «Океан» (фон-градиент, светлые матовые карточки с тёмным текстом) и «Чёрный океан» (тот же свет на чистом чёрном, тёмные карточки). Заменяют текущие светлую и чёрную.
- Переключатель в топбаре: «Авто / Океан / Чёрный» (авто — по prefers-color-scheme). Выбор пользователя сохраняется, как сейчас сохраняется тема; сверь с кодом. Если тема хранится на сервере у пользователя — значения старых тем перевести на новые без миграции (чтение: light→ocean, black/dark→black).
- Все цвета — только через токены из ocean.css; захардкоженные цвета в компонентах найди и замени, список — в отчёт.
- Статусные цвета (просрочено, скоро срок, в норме, инфо) — токены red/amber/green/blue с текстом и фоном. Цвет не единственный носитель смысла: у статуса всегда есть текст или иконка.

## 2. Компоненты и раскладка

- Каркас: плавающий стеклянный сайдбар (разделы, счётчики, активный пункт — акцентная «таблетка» со свечением), топбар (поиск, уведомления, аватар, переключатель темы), «сцена» — большая матовая панель с заголовком страницы, внутри карточки.
- Переведи на новые компоненты все экраны: дашборд, задачи и цепочки, реестры конструктора, уязвимости, активы, DLP и разрешения, доказательства, документы (В работе / Утверждённые, карточка, механизмы контроля), осведомлённость, самооценка (включая режим презентации), справочники, пользователи и роли, параметры, профиль и «Мои сессии», вход, страницы ошибок.
- Формы, модальные окна, выпадающие списки, тосты, вкладки, пагинация, пустые состояния, «Загрузка…» — в том же стиле. Модальные окна — стеклянная панель поверх затемнения.
- Таблицы: широкие таблицы прокручиваются внутри карточки, страница горизонтально не скроллится.
- Адаптив по брейкпоинтам эталона (1100 / 860 / 560). На телефоне сайдбар сворачивается в меню.

## 3. Экран мониторинга (настенный монитор)

- Тема «Чёрный океан» по умолчанию, без анимаций появления и без hover-эффектов.
- Стеклянное размытие (backdrop-filter) на мониторе оставить — решение принято, не спрашивать. Читаемость с расстояния при этом обязательна: крупные цифры и дни до срока, контраст не ниже, чем сейчас.

## 4. Подпись «designed by»

- Моя подпись из `signature/` в нижней части сайдбара: подпись «designed by» мелкими заглавными + SVG высотой ~42 px, справа версия портала. Анимация «пишется от руки» (sig-write) только при первой загрузке страницы, не при каждом переходе.
- Экран входа и «О портале» — полная подпись.
- Режим презентации самооценки: в углу «designed by Iskandar Masharipov» + «Подготовил: <ФИО открывшего> · <дата>», как договаривались раньше.
- Отдельного раздела под подпись нет. SVG вставляется инлайном или как локальный файл сборки, цвет через currentColor.

## 5. Шрифты и производительность

- Inter — только локальные файлы шрифта в сборке (woff2, лицензия OFL — положи текст лицензии рядом). Если файлов нет в репозитории — запасной стек `-apple-system, 'Segoe UI', system-ui, sans-serif` и вопрос ко мне в плане. Моноширинный — системный стек из эталона.
- backdrop-filter: проверь на Windows-ноутбуке отдела в Chrome и Edge (это основной парк). Если прокрутка длинных таблиц тормозит — blur только у сайдбара, топбара и модальных окон, у карточек таблиц — без blur, только полупрозрачный фон.
- prefers-reduced-motion отключает все анимации (как в эталоне).
- Размер бандла: сравни до/после, рост больше 10% — объясни.

## 6. Доступность

- Контраст текста WCAG AA (4.5:1 для обычного, 3:1 для крупного) в обеих темах, включая muted-текст на карточках и белый текст на акцентной кнопке. Посчитай для пар токенов, таблицу — в план; несоответствия исправь подбором токена, а не отдельными исключениями.
- Видимый фокус клавиатуры (кольцо акцентного цвета) на всех интерактивных элементах.

## 7. Проверки и тесты

- Быстрые проверки перед коммитом: typecheck, lint, frontend test, build.
- e2e: селекторы тестов не должны зависеть от классов оформления; если ломаются — переводи на роли/подписи/data-testid, а не ослабляй проверки. Полный e2e на ibportal_e2e — один раз перед тегом.
- Скриншоты ключевых экранов в обеих темах и на ширине 375 px (через Chrome DevTools в e2e-раннере), сложи в docs/design/ocean/screens/ для моего просмотра. Это не тесты сравнения, просто для проверки глазами.
- Репетиция выкладки: только замена frontend, migrate не нужен; проверь, что откат на предыдущий тег — тоже только frontend.

## 8. Коммиты

Токены и темы с переключателем → каркас (сайдбар, топбар, сцена) и подпись → общие компоненты (кнопки, формы, таблицы, модальные окна) → экраны группами → экран мониторинга → доступность и производительность → документация (concept.md раздел оформления, ADR «Дизайн „Океан“», руководство — скриншоты, CHANGELOG с «Влияние на данные: нет»).

После моего подтверждения плана: по коммиту на шаг, тег и выпуск — как в 1.11.0: при зелёных проверках сам, при красном — стоп и отчёт. Сообщение для DevOps — в файл deploy/verification/1.13.0-devops.txt.

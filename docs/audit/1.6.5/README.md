# Снимки экранов к аудиту 1.6.5–1.6.6

К `docs/ui-audit-1.6.5.md`. **Снимки в репозиторий не входят** (`docs/audit/**/*.jpg` и `*.png` — в `.gitignore`, решение владельца 04.11.2026). Полный набор хранится вне репозитория у владельца проекта:

| Набор | Что | Ширины |
|---|---|---|
| до / после | 1.6.4 до правок и 1.6.5, 13 экранов, обе темы | 1024, 1440, 1920 |
| до / после, 1280 | 1.6.4 (коммит `b2cf6e4`) и 1.6.5, те же экраны | 1280 |
| доска | самые длинные заголовки карточек; пробное ограничение в 3 строки (раздел 7 аудита) | 1280, 1366 |
| длинные строки | имя хоста без пробелов, sha256, три ФИО в «Могут взять», подставленные в карточки и панели | 1280, 1440, 1920 |
| колонка «Статус» | как было, варианты A и B, реализованный B | 1280, 1366 |

В этой папке в рабочей копии остаются:
- `*/overflow-report.md` — текстовые отчёты автоматической проверки переполнения по каждому снимку наборов «до / после» («ok» — элементы в границах своих контейнеров); входят в репозиторий;
- `status-col/docs-<ширина>-<тема>-<A|B>.jpg` — снимки вариантов колонки «Статус» (раздел 8 аудита; выбран B). Только локально, в git не попадают.

Снимки — dev-окружение с тестовыми данными e2e (банковских данных нет), headless Chrome; тема `light` или `dark` (чёрная, `#000`).

# Эталон дизайна «Океан» (1.13.0)

- `ocean.css` — токены тем «Океан» (`.t-ocean`) и «Чёрный океан» (`.t-black`) и стеклянные компоненты.
- `Main.dc.html` — дашборд (тема «Океан»), `Registers.dc.html` — реестр уязвимостей («Чёрный океан»). Разметка шаблонная (`<x-dc>`, `sc-if`, `{{ }}`) — образец вида, сетки и отступов, не код для копирования. Ссылки на Google Fonts и `/_blob/...` в макетах — артефакты среды макета: в портале шрифты только локальные, подписи — из `signature/`.
- `signature/` — подпись «designed by», чистый вектор (один path, без шрифтов и скриптов):
  - `signature-full*` — полное имя (экран входа, «О портале», титул презентации);
  - `signature-autograph*` — фамилия с росчерком (низ сайдбара, высота ~42 px);
  - `signature-initials*` — инициалы (угол режима презентации);
  - без суффикса — `fill="currentColor"` (для портала), `-white` (#F2F6F8) и `-navy` (#0B1C2C) — с готовым цветом.

Данные в макетах вымышленные.

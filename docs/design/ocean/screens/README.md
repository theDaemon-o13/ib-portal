- **`assessment-*`** — стенд, пользователь только с ролью «Самооценка» (09.11.2026): в прежних снимках вместо самооценки был дашборд — у пользователя e2e нет `assessment.manage`.
- Отдельной страницы «не найдено» в портале нет: неизвестный адрес ведёт на главную, поэтому снимков `not-found-*` нет.

## 1.13.4 — элементы форм

Dev-база, вымышленные данные, Chrome на macOS; обе темы, 1440 и 375 px.
- `forms-select-open-*` — открытый список «Раздел» в «Журнале» (рядом — поля даты); `forms-select-search-black-1440` — длинный список «Действие» с поиском; `forms-select-modal-ocean-1440` — список в окне «Новое письмо»; `forms-select-up-ocean-1440` — у нижнего края список открывается вверх.
- `forms-radio-*` — окно «Создать группу» (radio «Вид», чекбоксы «Типы систем»); `forms-checkbox-*` — матрица «Роли и права» (последний столбец — недоступные); `forms-file-*` — выбор файла в доказательствах.
- Системный календарь поля даты на снимок страницы не попадает (его рисует браузер) — он в цветах `color-scheme` темы.

## 1.13.5 — несколько ответственных лиц

Dev-база, вымышленные данные («Политика тестовая — доступ к информационным системам», «Иванов И.И.», «Петрова П.П.» и др.), Chrome на macOS; обе темы, 1440 и 375 px.
- `parties-list-*` — список «Выбрать из справочника»: поиск, отметки, двое выбраны (чипы над кнопкой), «Сидорова С.С.» — «уже добавлен», активный пункт с фокусом клавиатуры. На 375 px — внутри выезжающей панели (модальное окно).
- `parties-form-*` — форма «Добавить ответственных лиц»: чипы, строка ручного ввода, один «Срок ответа», «Добавить (3)».
- `parties-added-ocean-1440` — после добавления: трое с одним сроком, у каждого свои кнопки «Срок», «Снять», «Отметить согласование».

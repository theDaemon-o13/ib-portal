# Скриншоты «Океан» (1.13.0)

Для проверки глазами, не эталоны сравнения. Имя файла: `<экран>-<тема>-<ширина>.jpg`; тема `ocean` — «Океан», `black` — «Чёрный океан».

- **1440 px, обе темы** — сценарий `frontend/e2e/screens.shot.mjs` на одноразовой базе e2e, пользователь `e2e.dev` (06.11.2026, сборка 1.12.0-dev с «Океаном»).
- **375 px, обе темы, и `login-*-375`** — стенд репетиции 1.9.0 → 1.13.0 (`ibportal-v19check`, образы 1.13.0, через nginx), супер-администратор стенда, 09.11.2026. Данных на стенде мало: экраны в основном пустые.
- **`assessment-*`** — стенд, пользователь только с ролью «Самооценка» (09.11.2026): в прежних снимках вместо самооценки был дашборд — у пользователя e2e нет `assessment.manage`.
- Отдельной страницы «не найдено» в портале нет: неизвестный адрес ведёт на главную, поэтому снимков `not-found-*` нет.

- **`rail-<пользователь>-<тема>-<ширина>.jpg`** (1.13.1) — узкое меню: «Читатель документов» (`reader`) и пользователь «Самооценки» (`assessment`), обе темы, 1440 и 375 px (на 375 — меню открыто кнопкой «Меню»). Стенд, frontend 1.13.1, 09.11.2026. `assessment-*-1440.jpg` заменены снимками 1.13.1.

1.13.1: в 1.13.0 у пользователя с одним-двумя разделами меню уже (около 228 px), и подпись внизу («Версия …», «Закрытый контур») обрезалась. Теперь версия переносится под подпись; правый край версии — внутри меню во всех восьми вариантах.

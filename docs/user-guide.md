# Портал ИБ: краткое руководство пользователя

Портал отдела информационной безопасности: реестры (уязвимости, риски, устройства DLP, разрешения и свои), задачи, документы с согласованием, доказательная база, дашборд и экран мониторинга. Работает только во внутренней сети банка.

## Вход

- Адрес портала сообщает администратор. Открывайте его именно по этому адресу: по IP или другому имени портал перенаправит на правильный.
- Логин и пароль выдаёт администратор. Временный пароль при первом входе нужно сменить.
- Пароль: не короче 12 символов, минимум три вида символов из четырёх (строчные, прописные, цифры, знаки); нельзя повторять последние 5; действует 90 дней, потом портал попросит сменить.
- Значок глаза в поле пароля показывает и скрывает введённый пароль. «Запомнить логин» подставит логин при следующем входе; пароль портал не запоминает — его может сохранить только браузер (на своём рабочем месте).
- После 5 неверных попыток вход блокируется на 15 минут. Без действий 30 минут — выход: за 2 минуты портал предупредит («Продолжить работу»), а после входа откроет ту же страницу. Само обновление счётчиков и дашборда действием не считается — открытая, но забытая вкладка тоже закроется.
- Администраторы (права на настройки и пользователей) входят только со своих рабочих мест.
- Тема оформления — переключатель в меню: «Авто / Светлая / Чёрная».
- Внизу меню — версия портала: щелчок по ней открывает окно с версией и автором. Версию сообщайте администратору, если что-то не работает.

Что видно в меню, зависит от ролей. Без доступа к разделам ИБ виден только раздел «Документы».

## Дашборд

Ключевые показатели (открытые и просроченные уязвимости, инциденты за 30 дней, просроченные задачи, документы к пересмотру, риски без решения ОУР, доказательства), плитки-счётчики и графики по реестрам. Обновляется раз в минуту. **Любое число кликабельно:** открывается раздел с тем же фильтром, и количество записей там совпадает с числом.

«Настроить» — свой дашборд: перетащите элемент за ⠿, выберите размер S, M или L, скройте лишнее (скрытые — в списке «Скрытые», оттуда их можно вернуть), «Готово». «Сбросить» возвращает раскладку по умолчанию. Администратор с правом «Настройки» там же задаёт раскладку по умолчанию для роли.

## Мониторинг

Экран для настенного монитора: один экран без прокрутки, листается сам каждые 12 секунд. Панель управления появляется при движении мыши: назад, пауза, вперёд, на весь экран, закрыть. Клавиши: ← → — листать, пробел — пауза. Если связь с сервером пропала, экран показывает последние данные и время их обновления.

Слайды настраивает администратор с правом «Настройки»: «Настройки → Экран мониторинга» — добавить слайд (что показывать, сколько секунд, фильтры), порядок ↑↓, выключить, «Пропускать, если данных нет», «Предпросмотр» — как будет на мониторе. Мониторы подхватывают изменения сами в течение 1–2 минут.

**Показатели рассылок (с 1.9.0).** В слайд «Ключевые показатели» можно добавить «Ближайшая рассылка» (дней до отправки, под числом — правило и дата; красным, если этап просрочен) и «Рассылки с просрочкой». По умолчанию их на слайде нет. Чтобы добавить: «Настройки → Экран мониторинга» → слайд «Ключевые показатели» → «Изменить» → отметьте оба показателя и снимите два других, чтобы осталось **не больше 8**, иначе слайд не поместится на экран. Проще всего убрать показатели, у которых есть свой слайд: «Срок устранения в ближайшие 7 дней» (слайд «Уязвимости по срокам») и «Доказательства истекают» (слайд «Доказательства»). Проверьте «Предпросмотром».

## Конструктор реестров

Вверху — выбор реестра и вкладки «Записи», «Поля», «Автоматизация».

- **Записи.** Таблица на весь экран: поиск по реестру, сортировка по колонке, фильтры. Колонка «Дней до срока» — «Просрочено», «Осталось», «В срок», «Закрыто»; реестр со сроками открывается «срочное сначала». Щелчок по строке — карточка записи справа: правка, история изменений, связанные задачи и файлы; «Сохранить» — внизу карточки. Открытая запись — в адресе страницы (ссылкой можно поделиться), «Назад» в браузере закрывает карточку. Если запись успел изменить другой сотрудник, портал не сохранит правку и предложит «Перечитать запись».
- **Сравнение.** В окне импорта выгрузки реестра кнопка «Сравнение» показывает открытые записи, которых нет в загруженном файле. Выберите область (например, отчёт или систему; «Весь реестр» — только для полной выгрузки), отметьте записи и выберите статус — в строке или «Статус отмеченным». Портал покажет, сколько записей изменится, и попросит подтвердить. Если в отчёте сканера нет хостов прошлого отчёта, портал предупредит «неполный скан»: хост мог быть выключен — уязвимость не обязательно устранена. Сам файл сохраняется в портале и указывается в истории записи. Ключ сравнения и поля области задаются на вкладке «Поля», блок «Сравнение с реестром».
- **Excel.** «Экспорт в Excel» — файл с колонкой ID и листом «Справка». Заполненный файл загружается обратно кнопкой «Импорт из Excel»: сначала предпросмотр (что добавится, изменится, строки с ошибками), потом «Применить» — всё или ничего. Пустой ID — новая запись; пустая ячейка значение не меняет; сотрудник — «ФИО (логин)»; серые колонки (вычисляемые) при импорте не меняются.
- **Поля и автоматизация** — для пользователей с правом настройки реестров: добавить поле (у текстового — «Многострочный текст»: в карточке поле от 6 строк, до 20 000 символов), назначить заголовок и статус, правила «условие → действие» (напоминание, уведомление, эскалация), которые создают задачи получателям.
- **Удаление** — по отдельному праву, с причиной из списка («Ошибочный импорт», «Дубль», «Другое» с пояснением). Удалённая запись попадает в «Настройки → Корзина», восстановить её может супер-администратор. Обычно запись отправляют в архив: это обратимо и без корзины. Записи уязвимостей удаляются только по праву «Удаление данных». Запись с открытыми задачами или ссылками из других записей удалить нельзя — только в архив; сначала закройте или удалите задачи. То же для записи с решениями другого отдела или доказательствами.
- **Несколько записей сразу.** Отметьте галочки слева (галочка в заголовке — все на странице, затем «Выбрать все N по фильтру»). На панели — «Архивировать выбранные» или «Удалить выбранные». Портал сначала покажет, что произойдёт, и спросит подтверждение; в итоге — сколько удалено и сколько ушло в архив и почему.
- **Архив.** Кнопка «Архив» над таблицей показывает записи в архиве; отметьте нужные и нажмите «Вернуть выбранные». «← К записям» — назад.
- **Удалить все записи** — в меню реестра «⋯»: портал покажет число записей (с архивными), попросит причину и название реестра.
- **Удалить реестр** — в меню реестра «⋯», право «Удаление данных». Системные реестры (уязвимости, инциденты, риски ИБ, сервисы, компоненты, хосты) не удаляются: пункт неактивен. Нельзя удалить и реестр, на который ссылаются поля-связи других реестров: окно перечислит эти поля. Скроются записи, автоматизации и плитки дашборда; задачи автоматизаций останутся с пометкой «реестр удалён». Нужны причина и название реестра.

### Реестр уязвимостей

Записи и сканы живут в разделе «Уязвимости». На этой странице реестр уязвимостей виден целиком: выгрузка, обратный импорт по колонке ID, массовые действия и аналитика работают по всем узлам. «Новая запись», загрузка отчёта сканера и «Сравнение» здесь недоступны; строка с пустым ID при обратном импорте — ошибка.

### Риски ИБ

Решение ОУР вносится в карточке риска кнопкой «Внести решение» и только с файлом документа-основания; документ сразу попадает в доказательную базу.

### Устройства DLP и разрешения на доступ

Разрешение — запись с PDF документа-основания и связью с устройствами. «Выгрузка для проверки» (zip) — записи за период в Excel и файлы-основания одним архивом.

## Уязвимости

Слева дерево: группы (сервисы и подразделения), внутри — типы систем, под ними сканы. Число — открытые записи, красное — просроченные. Точка у скана: зелёная — передан ИКТ, оранжевая — ждёт передачи. Создать группу, добавить тип и переименовать группу может пользователь с правом настройки реестров.

- **Импорт скана.** Откройте тип систем, нажмите «Импорт скана» и выберите .xlsx отчёта сканера. Названия листов не важны: хосты ищутся по колонке «Имя хоста», находки — по колонкам «Пакет» и «CVE» или «Идентификатор». Дата скана берётся из имени файла, её можно поправить. Система необязательна: по ней задачи получает владелец системы.
- **Профили сканирования.** Один отчёт — один профиль: Windows, Linux, PostgreSQL, Website или Docker. Сравнивайте скан только с реестром своего профиля, иначе все открытые находки окажутся в «Пропали». Если имя файла указывает на другой профиль, портал предупредит и загрузит файл только после галочки «Я проверил, файл относится к этому узлу». Подтверждение видно в скане и в журнале. Если профиль в имени не найден, предупреждения не будет.
- **Перед первой группой.** Отправьте в архив прежние типы в «Настройки → Справочники → Типы систем»: Рабочие станции, Серверы, БД, Сетевое оборудование, Веб-приложения.
- **Импорт со страницы группы.** На странице группы нажмите «Импорт скана» и выберите файл: портал предложит узел по профилю, можно выбрать другой. Если такого типа в группе нет, с правом «Конструктор реестров» доступна кнопка «Добавить тип и импортировать», без него выберите существующий узел. Узел появится только после подтверждения импорта: отмена ничего не оставляет.
- **Сменить тип.** На странице узла, право «Конструктор реестров». Доступны только типы, которых нет в группе. Реестр, сканы и продления остаются у узла, смена видна на вкладке «История».
- **Регулярность.** В дереве и на карточках видно, сколько дней прошло с последнего скана. Дольше порога (90 дней) подпись выделена, а такие узлы перечислены на экране «Все группы» и в разделе «Активы».
- **Предпросмотр.** Пока вы не подтвердили, ничего не меняется. Строки разложены на пять групп: новые, повторно обнаруженные (были «Устранена»), изменившиеся, без изменений и пропавшие (открытые записи, которых нет в файле). Новые, повторные и изменившиеся выбраны сразу, пропавшие — нет: отметьте те, что действительно устранены. Если из охвата выбыли хосты, портал предупредит: запись могла пропасть, потому что хост не сканировали. Пустое значение в файле не стирает значение в реестре. «Риск принят» при новом скане не открывается.
- **Передача ИКТ.** Импорт срок не запускает. На экране скана нажмите «Передать ИКТ»: дата, кому, файл письма по желанию. Передача делается один раз. Срок идёт от первого переданного скана, в котором запись встречалась; следующие сканы его не сдвигают. До передачи статус записи — «Не передано ИКТ».
- **Срок.** Оценка = CVSS × Кэ × Ки, критичность считается сама, её можно выбрать вручную. Срок: критическая — 14 дней, высокая — 30, средняя — 90, низкая — 180 от передачи ИКТ; окончание на выходном переносится на рабочий день. Компенсирующие меры и «Срок после пересмотра ИБ» главнее всего остального. Карточка записи показывает базовый срок, каждое продление, решение и итог.
- **Обновить сроки.** Нужно право «Уязвимости: изменение сроков» (назначает администратор). Кнопка есть у типа систем и у группы. Дни задаются по Уровню сканера, только продление, с обоснованием ОИКТ: номер обращения, дата и файл. Перед применением видно «было → станет». Записи с решением п. 7.3 и не переданные ИКТ не участвуют. Отмена — только целиком: сроки возвращаются, событие остаётся с отметкой «Отменено».
- **Удаление** (право «Удаление данных», назначает администратор). Всё удалённое попадает в «Настройки → Корзина», восстановить может супер-администратор.
  - **Группа** — «Удалить группу», **тип систем** — «Удалить тип из группы». Можно только без открытых записей («В работе», «Просрочена», «Не передано ИКТ»): окно покажет, в каких типах они есть. Перенесите или закройте их. Скроются устранённые и архивные записи и сканы, продления останутся в истории. Укажите причину; для группы ещё введите её название. Название удалённой группы можно сразу дать новой.
  - **Запись** — в карточке «Удалить запись» или галочки в реестре узла и «Удалить выбранные». Причина обязательна: «Ошибочный импорт», «Ложное срабатывание», «Дубль» или «Другое» с пояснением. Удалённая запись не считается в показателях, сроках и эскалациях.
  - Если удалённая запись снова пришла в скане этого узла, в предпросмотре она в группе «Были удалены» с причиной. По умолчанию она не загружается; отметьте её, если нужна, — заведётся новая запись.
  - Сколько записей удалено и почему, видно над карточками на «Все группы», в группе и в типе систем: период 30, 90 или 365 дней, ссылка «Корзина». Удалённые открытые записи считает и сверка активов (раздел 5.3).
- **«Без группы».** Сюда при обновлении попали записи прежнего реестра со сроком, который был на тот момент. Группа не удаляется. Когда в ней не остаётся записей, она пропадает из дерева и «Все группы», а её сканы открывает ссылка «Архив сканов прежнего реестра» на «Все группы». Откройте «Из прежнего реестра» и нажмите «Перенести» или отметьте несколько записей и нажмите «Перенести выбранные». Срок сохраняется. Если такой ключ «Пакет + Идентификатор» в узле уже есть, запись не перенесётся, причина покажется по строке.
- За 3 дня до срока, при просрочке и через 10 рабочих дней просрочки без мер портал сам ставит задачи (руководителю ДИКТ, владельцу системы, руководству и начальнику ИБ).

## Активы

Три реестра по процедуре классификации ИТ-активов:
- **«Сервисы»** — продукты: владельцы, категория критичности, RTO и RPO, дата классификации, пересмотр;
- **«Компоненты»** — сервисы-компоненты продуктов: микросервисы, базы данных, прокси, с IP-адресом и портом;
- **«Хосты»** — серверы, рабочие станции, сетевое оборудование.

Раздел «Активы» показывает, что между ними не сходится, а также с KSC, сканами, DLP и рисками. Он только читает данные; правки вносятся в реестрах, ссылки ведут на нужные записи.

Категории: Mission Critical, Business Critical, Operational, Non-Critical. Значимые — первые две. Подсказка под полями RTO и RPO напомнит значения по категориям из процедуры. «Пересмотр до» портал считает сам: дата классификации + 183 дня. За 30 дней до срока придёт задача участникам метки «Активы».

### Как заполнить в первый раз

1. **Продукты.** Внесите продукты из Приложения 2 процедуры вручную или файлом через «Импорт из Excel» в реестре «Сервисы».
2. **Команды → продукты.** Попросите супер-администратора заполнить «Параметры портала → Активы: команды → продукты», если несколько команд относятся к одному продукту. Команда без соответствия станет продуктом со своим именем.
3. **Реестр сервисов.** В реестре «Компоненты» нажмите «Импорт реестра сервисов» и выберите файл формы как есть — шапку удалять не нужно. В предпросмотре:
    - «Будут созданы продукты» — продукты, которых ещё нет;
    - «Будут созданы хосты» — серверы по IP-адресам компонентов; снимите галочку, если создавать их не нужно;
    - предупреждения о неизвестной шкале, неполных адресах и новых местоположениях.

   Ничего не меняется, пока вы не нажмёте «Применить».
4. **Отчёты Kaspersky.** В реестре «Хосты» нажмите «Импорт отчёта KSC» — сначала откроется окно «Как загружать отчёты KSC» с порядком отчётов и тем, что проверить в KSC до выгрузки (его можно отключить галочкой «Больше не показывать» и открыть снова кнопкой «Как загружать»). Загрузите по очереди отчёт о развёртывании защиты, о статусе антивирусных баз и о версиях программ. Каждый отчёт обновляет только свои поля. Список «Нет в файле» строится только по отчёту о развёртывании и только среди хостов, которые уже были в KSC. Статус «Выведен» ставите вы.
5. **Серверы по сканам.** Проверка «Хост из сканов есть в реестре» подскажет, кого не хватает; «ОС хоста указана» — где ОС можно взять из скана.

Повторная загрузка того же файла ничего не меняет. Лимит файла — 25 МБ и 20 000 строк. Отчёт на 5000 устройств загружается примерно за 10 секунд.

### Отчёты KSC: инструкция для администратора Kaspersky Security Center

Раз в месяц выгружайте три отчёта для группы «Управляемые устройства»:
- «Отчет о развертывании защиты»;
- «Отчет о статусе антивирусных баз»;
- «Отчет о версиях программ "Лаборатории Касперского"».

KSC по умолчанию ограничивает детальную часть отчёта 1000 записями. Если устройств больше, портал не примет отчёт: «Отчёт обрезан: в сводке N устройств, в таблице M». Откройте свойства шаблона отчёта и поднимите «Максимальное количество записей» выше числа устройств, затем выгрузите заново.

Формат файла оставьте как есть: `.xls`, который сохраняет KSC (это XML), портал принимает. Подойдёт и `.xlsx`, если файл пересохранили в Excel. Отчёты о владельцах устройств и о реестре оборудования не нужны — портал их не примет и скажет почему.

### Сверка

Проверки сгруппированы по разделам методики самооценки. Под названием раздела есть «Что требует методика»: целевое состояние и критерии уровней 1–4. Там же «Ссылка на раздел». Кнопка «Открыть в самооценке» видна только с ролью «Самооценка». Ваши оценки и баллы другие сотрудники здесь не видят.

«Нет данных» значит, что источник пуст или проверять нечего. Выведенные записи не считаются. Если имена двух хостов совпали без учёта домена, появится предупреждение: проверьте обе записи, портал их не объединяет. Дубли внутри одного отчёта KSC портал показывает в предпросмотре — удалите устаревшие записи в консоли KSC.

Значимые категории, неподдерживаемые ОС, минимальную версию защиты и правила типа хоста задаёт супер-администратор в «Настройки → Параметры портала».

## Осведомлённость

Два реестра в разделе «Реестры»: «Сотрудники» (выгрузка HR) и «Результаты INDIGO» (тестирование на платформе INDIGO). Смотреть может каждый сотрудник ИБ. Загружать и править — с правом «Записи реестров: правка».

1. **Загрузить сотрудников.** «Сотрудники» → «Импорт из Excel». Колонки называются как поля реестра: «Табельный номер», «ФИО», «Подразделение», «Должность», «Статус»…
    - Записи ищутся по табельному номеру.
    - ФИО одной колонкой портал сам делит на фамилию, имя и отчество. Если не получилось (составная фамилия, лишние слова), в предпросмотре будет предупреждение.
    - Новый сотрудник без статуса — «Работает».
    - Если колонки «Статус» нет, а в файле встретился уволенный, портал предупредит, но статус не изменит.
    - Тех, кого нет в новой выгрузке, отметьте «Уволен» кнопкой «Сравнение» в окне предпросмотра. Записи не удаляются: на них ссылаются результаты.
2. **Подготовить отчёт INDIGO.** Отчёт «Статистика по баллам» приходит как `.xls` старого формата — откройте его в Excel и сохраните как `.xlsx`.
3. **Загрузить отчёт.** «Результаты INDIGO» → «Импорт отчёта INDIGO». В предпросмотре:
    - сведения: тест, строк в таблице, средний процент по сводке и по строкам, проверка полноты (если не сошлось — отчёт может быть обрезан);
    - строки с ошибками (неразбираемая дата, процент не числом) — с номером строки отчёта, они не загружаются;
    - «Повторы в один день» — из нескольких попыток одного человека в один день загружается лучшая.

   Оценка и «На пересдачу» ставятся по порогам из «Параметров портала» на момент загрузки. Повторная загрузка того же отчёта ничего не меняет.
4. **Разобрать несопоставленных.** Сотрудник подставляется сам, только если полное ФИО с отчеством совпало ровно с одним работающим. Остальные — в блоке «Требуют ручного сопоставления» с причиной («однофамильцы: 2», «нет отчества», «не найден»). Выберите однофамильца из списка или «Найти…», либо оставьте пустым — строка будет «Не сопоставлен».
    - Позже: «Обновить по сотрудникам…» на экране «Результатов» находит «Не сопоставлен», для которых теперь есть ровно один работающий сотрудник (например, после новой выгрузки HR). Любую строку можно снять.
    - Сотрудника можно сменить и в карточке результата — «Сопоставление» станет «Вручную».
5. **Где смотреть, кому на пересдачу.** Виджет дашборда «На пересдачу»: число и последние попытки. Щелчок по числу открывает список с тем же числом. Уволенных в нём нет: связь на уволенного показывается с меткой «(уволен)», и такие записи исключаются. Рядом — «Средний результат по подразделениям» от худшего к лучшему.

Пороги оценки меняет супер-администратор: «Настройки → Параметры портала → Осведомлённость: пороги оценки».

## Учебные письма

Раздел «Осведомлённость» в меню: «Письма», «Шаблоны», «Расписание». Работают все сотрудники ИБ, утверждает начальник ИБ (пользователь с отметкой «Является начальником ИБ»). Портал писем не отправляет: готовое письмо вы вставляете в Outlook или WorldClient и отправляете оттуда, а в портале отмечаете отправку.

### Письмо от черновика до «Отправлено»

1. **Создать.** «Письма» → «Новое письмо»: название (только для списков, в письмо не входит) и тип. Плановое — по графику, срочное — с поводом (инцидент, новая схема мошенничества, предупреждение регулятора).
2. **Написать.** Вкладки RU и TJ: тема и текст. На вкладке точка: ● — заполнено, ◐ — только тема или только текст.
    - Панель редактора: заголовки, жирный, курсив, подчёркнутый, зачёркнутый, списки, цитата, линия, ссылка, изображение, таблица, «Подпись ИБ» (✍) — блок с подписью отдела, она подставится сама.
    - Изображения — файлом (🖼), перетаскиванием или из буфера: PNG, JPEG, GIF до 1 МБ. Текст прошлого письма из Outlook или Word часто приносит картинки ссылками — портал скажет «Не вставлено изображений: N». Сохраните картинку файлом и вставьте заново.
    - Справа сверху — размер письма. От 1 МБ — предупреждение (письмо ляжет на сервер 1500+ раз), больше 2 МБ не сохранится.
    - Ссылки на сам портал в письмо не вставляются: сотрудники банка его не видят.
3. **Сохранить.** Каждое сохранение — новая версия. Если письмо тем временем изменил коллега, портал предложит «Перечитать письмо».
4. **На согласование.** Плановому письму нужны тема и текст на обоих языках, срочному — хотя бы на одном (тогда пометка «только RU» или «только TJ»). Переменные `{{…}}` должны быть заполнены. Чтобы поправить письмо на согласовании, нажмите «Отозвать».
5. **Начальник ИБ** открывает письмо: «Утвердить» или «Вернуть на доработку» с комментарием — тогда автору (или исполнителю задачи письма) приходит задача «Доработать письмо». Если начальник ИБ сам писал или правил письмо, утверждение помечается «без независимого согласования».
    - Утверждённое письмо ещё можно поправить, но утверждение снимется — портал спросит. Название меняется без этого.
6. **Отправить из почты.** Вкладка «Экспорт» (раздел ниже) — вставьте письмо в Outlook или WorldClient и отправьте.
7. **Отметить отправленным.** Дата отправки (не позже сегодня) и аудитория: «Все сотрудники» или подразделения через запятую — подсказки из реестра «Сотрудники» и прошлых рассылок. Письмо замораживается: текст и подпись на дату отправки больше не меняются. В реестре «Рассылки» появляется запись.
    - Разослали ещё раз (другим подразделениям) — «Отметить отправленным ещё раз»: новая запись, текст тот же.
    - Нужно похожее письмо — «Создать копию»: новый черновик с тем же текстом.
    - Срочное письмо можно отметить «Отправлено без согласования» — с причиной. Это видно в карточке, журнале и в поле «Согласование» реестра «Рассылки».

Вкладка «Версии»: открыть любую версию, сравнить две («было → стало» по строкам, отдельно для RU и TJ), «Восстановить» старую — она станет новой версией. «События» — кто отправлял, утверждал, возвращал и отмечал отправку.

### Письмо из шаблона

«Шаблоны» — письма-заготовки с переменными `{{описание}}`, например «Вам звонят от имени {{организация}}». Одинаковое имя в RU и TJ — одна переменная; для разных значений по языкам нужны разные имена («{{тема RU}}», «{{тема TJ}}»). `{{подпись}}` — блок «Подпись ИБ».

«Письмо из шаблона» (в списке шаблонов или в карточке шаблона): выберите шаблон, заполните поля переменных простым текстом — получится черновик. Отметка «больше текущего лимита» у шаблона значит, что лимиты размера уменьшили после его сохранения: уменьшите изображения, иначе по расписанию черновик из него не создастся.

### Правило расписания

«Расписание» → «Новое правило»:
- **периодичность**: ежемесячно в день N, дважды в месяц, ежеквартально (день и месяц квартала), ежегодно, каждую N-ю неделю;
- **дата начала** и **опережение** (7–90 дней, по умолчанию 10) — за столько дней до отправки появится задача;
- **роль-исполнитель** — кто может взять задачу (видят её все сотрудники ИБ); **шаблон** — тогда черновик письма создаётся сразу.

«Ближайшие 6 дат» показывают, когда будут рассылки: дата на выходной или праздник переносится на предыдущий рабочий день, причина видна рядом. Задачи «Рассылка: <правило> — <дата>» создаются раз в час; «Проверить сейчас» — сразу. В задаче — этапы с датами: черновик (за 7 дней), согласование (за 3), отправка; этап выполнен, когда письмо отправлено на согласование, утверждено, отмечено отправленным. Возьмите задачу («Взять себе»), откройте письмо по ссылке или создайте его кнопкой «Создать письмо» / «Письмо из шаблона». Отметка «Отправлено» задачу не закрывает — завершите её как обычно. Если задачу никто не взял за 3 рабочих дня до отправки, начальнику ИБ придёт уведомление.

Правку правила, отключение и архив можно делать в любое время: созданные задачи и письма не меняются.

### Срочная рассылка

«Письма» → «Срочная рассылка»: название, повод, при желании шаблон. Портал создаст срочное письмо и задачу вам на 1 рабочий день с высоким приоритетом. Срочному письму хватает одного языка; если согласовать некогда — «Отправлено без согласования» с причиной.

### Экспорт и проверка в почтовом клиенте

Вкладка «Экспорт» в карточке письма: язык (RU, TJ или RU + TJ — сначала русский, затем линия и таджикский), версия (по умолчанию последняя, у отправленного — отправленная).
- **«Скопировать с оформлением»** — затем вставьте в новое письмо (Ctrl+V). Если браузер не дал доступа к буферу — выделите текст в предпросмотре и нажмите Ctrl+C.
- **«Скачать .eml»** — файл откроется в почтовом клиенте как неотправленное письмо: тема уже заполнена, получателей добавьте сами. Изображения вложены в файл.
- **«Печать / PDF»** — страница письма без меню портала; в окне печати выберите «Сохранить как PDF».

**Перед первой рассылкой сотрудникам** проверьте экспорт на тестовом письме самому себе — в каждом клиенте, которым пользуется отдел (Outlook и WorldClient):
1. Письмо с заголовком, списком, таблицей, ссылкой, изображением и «Подписью ИБ», на обоих языках.
2. «Скопировать с оформлением» → вставить в новое письмо → отправить себе. Сравнить с предпросмотром: шрифт, заголовки, таблица с рамками, ссылка нажимается, изображение на месте, подпись есть.
3. «Скачать .eml» → открыть файл в клиенте → тема по-русски и по-таджикски читается без «кракозябр», изображение на месте → отправить себе.
4. Открыть полученные письма в Outlook, в WorldClient и на телефоне: изображения не превратились во вложения, текст не съехал, ссылка ведёт куда нужно.
5. Записать результат в журнал проверки (что не так и в каком клиенте) — передать разработчику.

Что проверить особенно внимательно (возможные ограничения клиентов, подтверждаются этой проверкой):
- вставка из буфера с изображениями: часть клиентов не принимает изображения, вставленные как данные, — тогда используйте «.eml»;
- открытие файла `.eml` как черновика: в веб-почте может не работать — тогда «.eml» открывают в Outlook, а в WorldClient вставляют копированием;
- размер изображений: настольный Outlook может не уменьшать широкие картинки под окно — вставляйте изображения не шире 600 пикселей;
- таблицы и цитаты: оформление (рамки, отступы) в разных клиентах может немного отличаться.

## Параметры портала

«Настройки → Параметры портала», только роль «Супер-администратор». Порог регулярности сканирования, синонимы профилей, значимые категории и таблицы реестра активов, пороги оценки INDIGO, размер учебных писем (изображение, письмо, предупреждение; с 1.9.0). Неверное значение не сохранится, портал объяснит почему. Если значение не меняли, действует значение по умолчанию, его видно под формой. «Сбросить к умолчанию» возвращает его. Каждое изменение записывается в журнал: было и стало.

## Поиск

Строка поиска вверху меню: записи всех реестров, доказательства, файлы и **текст внутри PDF**, цепочки задач (по названию и номеру). Не меньше двух символов.

## Уведомления

- Числа в меню — только то, что ждёт **вашего** действия: у «Задачи» — задачи на вашей проверке, у «Документы» — документы, которые ждут вас. На колокольчике рядом с «Портал ИБ» — их сумма; то же число — в заголовке вкладки браузера, например «(3) Портал ИБ». Непрочитанные уведомления на колокольчике не отмечаются — они выделены в списке, который открывается щелчком. Обновляется само примерно раз в минуту. Просроченные задачи отдела — на дашборде и на доске с фильтром «просрочено».
- Щелчок открывает список: «Непрочитанные» и «Все», «Прочитать все». Щелчок по уведомлению отмечает его прочитанным и открывает задачу или документ.
- Что приходит: задачу назначили вам или сняли с вас; задача ждёт вашей проверки; вашу задачу вернули в работу, приняли или перенесли в другую колонку; новый комментарий в задаче, где вы исполнитель или автор; срок завтра; задача просрочена. По документам: документ ждёт вашего действия (согласования, перевода, подписанного PDF); документ вернули на доработку; новый комментарий к вашему документу; перенесли срок перевода или ответственного лица; срок ответственного лица завтра или просрочен. О собственных действиях уведомлений нет.
- С правом «Журнал действий» приходит ещё одно уведомление: служебный администратор назначил или снял роль, изменил права роли или сбросил пароль. Число непрочитанных таких уведомлений видно у пункта «Журнал», щелчок по уведомлению открывает журнал по этому администратору.
- Прочитанные уведомления хранятся 90 дней, непрочитанные — 180.

## Задачи

- Доска по колонкам «Backlog / Поставленные / В работе / На проверке / Выполнено» (администратор может добавить свои). Backlog — задачи без исполнителя; назначили исполнителя — задача в «Поставленные». Фильтры по категориям, «Архив». Панель «Загрузка сотрудников» справа скрывается кнопкой «Скрыть» и открывается кнопкой «Загрузка сотрудников» над доской — так колонкам шире; выбор запоминается.
- Быстрая постановка — строка над доской. «Задача из письма»: вставьте текст письма, портал разберёт отправителя, тему и срок («до ДД.ММ», «завтра», «в течение N рабочих дней», «срочно»), проверьте черновик и создайте задачу.
- Карточка: описание, ответственный, срок, комментарии, история; у задач из реестров — ссылка на запись. Кнопка шага процесса и «Сохранить» — внизу карточки, видны при любой длине истории. Открытая задача подсвечена на доске.
- Доска шире окна прокручивается по горизонтали (колёсиком над рядом фильтров, жестом или полосой прокрутки); длинная колонка прокручивается сама, её заголовок со счётчиком остаётся сверху. Если перетаскивать карточку к краю доски, доска прокрутится сама.
- Статус меняется кнопками. На карточке доски — кнопка вашего следующего шага: «Взять себе», «Взять в работу», «На проверку» (или «Завершить»), «Проверить». В карточке задачи — «Отправить на проверку», «Завершить», «Принять», «Вернуть в работу»: если для шага нужен комментарий, появится поле, и кнопка станет активной, когда вы его заполните. Комментарий шага виден в ленте с пометкой, откуда и куда перешла задача.
- Перетаскивать карточки и выбирать статус списком может только пользователь с правом «Задачи: свободная смена статуса». Если колонка требует комментарий, при переносе откроется окно «Комментарий к переходу».
- Кто что может: взять задачу из Backlog себе — любой сотрудник ИБ; взять в работу и отправить на проверку — исполнитель; принять или вернуть в работу — автор задачи или руководитель исполнителя с правом «Задачи: проверка» (свою задачу не принять). Поставить задачу другому — право «Задачи: постановка другим», перетаскивать карточки — «Задачи: свободная смена статуса».
- Проверяет задачу руководитель исполнителя (указан в «Настройки → Пользователи и роли»; если он отключён — следующий выше). Он виден на карточке: «Проверяет: <ФИО>»; «Принять» и «Вернуть в работу» есть только у него. Если руководителя нет, проверки нет: исполнитель нажимает «Завершить».
- С правом «Задачи: свободная смена статуса» в карточке задачи «На проверке» есть «Заменить проверяющего» — выберите сотрудника, комментарий по желанию. Из «На проверке» перетаскивает только проверяющий; задачу исполнителя с руководителем нельзя перетащить в «Выполнено» мимо проверки. Ненужную задачу отправьте «В архив».
- Супер-администратор не получает права процесса задач; тем, кто ставит задачи другим, нужна роль «Начальник ИБ» или роль с правом «Задачи: постановка другим» (`tasks.assign`). Право «Задачи: проверка» с 1.4.0 не используется (только для задач, отправленных на проверку раньше).
- **Цепочки** — задачи с одной темой, как переписка «RE: тема» в почте. Начните вводить название задачи (или разберите письмо) — если тема уже встречалась, под названием появится «Похоже на цепочку „…“». «Добавить в цепочку» — задача создастся сразу в ней; «Создать цепочку из этих задач» — объединить с задачами без цепочки на ту же тему; «Создать новую» — новая цепочка из этой задачи. Подсказку можно закрыть крестиком: задача создастся и без цепочки. Закрытая цепочка предлагается с кнопкой «Вернуть в работу и добавить» (её может открыть создатель цепочки, ответственный или руководитель с правом «Задачи: постановка другим»).
- На доске две и больше задач цепочки в одной колонке — карточка-стопка «название · N задач, M выполнено · здесь K»; одна задача цепочки в колонке — обычная карточка с меткой «Цепочка: …» (щелчок по метке открывает цепочку). Щелчок по стопке раскрывает задачи этой колонки — с ними работают как обычно, проверка у каждой задачи своя. «Группировать по цепочкам» выключает группировку; поиск над доской ищет и по названию цепочки, список «Цепочка» оставляет задачи одной цепочки.
- В карточке задачи — блок «Цепочка»: все задачи цепочки по дате (с выполненными и архивными), «Отвязать», «Перенести в другую цепочку…», «Добавить в цепочку…».
- «Цепочки» над доской — список цепочек с фильтрами. В панели цепочки — название, ответственный, срок, сводка и задачи. Когда все задачи выполнены, портал предложит «Закрыть цепочку» — сама она не закрывается. Закончили работу — «Закрыть»; «Удалить» отвязывает задачи (сами задачи остаются), восстановить цепочку нельзя.
- «Найти цепочки среди старых задач» (на экране «Цепочки», право «Задачи: постановка другим» или «Настройки»): портал покажет группы задач с одинаковой темой, отметьте нужные и подтвердите. Запускать можно сколько угодно раз.
- Архивировать может любой сотрудник ИБ, удалить — по отдельному праву.
- «Отчёт» (право «Задачи: отчёт») открывает страницу выполненных задач. Период — кнопками «Этот месяц», «Прошлый месяц», «Квартал», «Год» или датами; фильтры — сотрудник, категория, «только с опозданием», «с архивом». Сверху — сколько выполнено, доля в срок, сколько с опозданием и на сколько в среднем, среднее время от взятия в работу до выполнения. Ниже — выполнено по неделям (в срок и с опозданием), по сотрудникам (щелчок по строке — отчёт по этому сотруднику), по категориям и список задач: когда взята в работу, когда выполнена, срок, опоздание, кто принял. Список сортируется щелчком по заголовку. Наведите на столбец или строку — появится подсказка с числами. Задачи, переданные другому ответственному (например, при смене начальника ИБ), в отчёт сотрудника не входят — они в архиве.
- «Выгрузить в Excel» на странице отчёта — выполненные задачи за выбранный период и фильтры. «Расширенная выгрузка» — все задачи: период по дате создания, сроку или выполнению, автор, колонка; в файле — автор, исполнитель, срок, колонка, даты шагов и дни просрочки, на листе «Параметры» — по какому фильтру отчёт построен.
- Несколько задач сразу: «Выбрать» над доской, щёлкните по карточкам, затем «Архивировать выбранные» или «Удалить выбранные». Список «Все источники» оставляет на доске задачи одного правила автоматизации.
- Правило автоматизации в архив или удаление: портал спросит, что сделать с созданными им задачами — оставить, отправить в архив или удалить (можно только нетронутые, без комментариев сотрудников). Там же, на вкладке «Автоматизация», — «Журнал запусков» и его очистка.

## Документы

- Реестр внутренних документов ИБ со статусами «черновик → на согласовании → утверждён → на пересмотре».
- Карточка выбранного документа — справа от реестра и остаётся на экране при прокрутке; кнопки этапа («На согласование…», «Приложить файл документа», «Открыть в OnlyOffice») — внизу карточки. На узком окне карточка выезжает справа поверх реестра. Если реестр узкий, колонки «Владелец», «Версия» и «Утверждён» не показываются — они есть в карточке документа; статус виден всегда. Выбранный документ — в адресе страницы: ссылкой можно поделиться, «Назад» в браузере возвращает к предыдущему.
- Над реестром — фильтры «Тип документа», «Автор» (владелец документа) и «Срок пересмотра» (срок прошёл, в ближайшие 30 или 90 дней, в ближайший год, до даты); «Сбросить» снимает их. В фильтр по сроку попадают только утверждённые документы: у черновика срока пересмотра нет. Фильтры работают вместе с кнопками «Ждут вас», статусами и «Архивом».
- Порядок реестра: «По типам» (по умолчанию) — дерево, сначала политики, затем остальные типы по алфавиту, внутри типа — документы по алфавиту; ветку типа можно свернуть щелчком по её названию. «По алфавиту» — один список по названию. Выбранный порядок запоминается в браузере.
- Файл документа живёт в OnlyOffice банка: в портале хранится ссылка на него и файлы, которые фиксируют текст на маршруте.
- Файлы документа открываются в портале на весь экран: щёлкните по имени файла в карточке (файл автора, согласованная и финальная версии, подписанный PDF, ответы ответственных лиц, переводы, записка к возврату). Страницы листаются стрелками ← →, масштаб — «+» и «−» (кнопка с процентами возвращает «по ширине»), Esc закрывает просмотр. Картинки открываются тем же окном.
- Для просмотра в портале приложите PDF; .docx открывается в OnlyOffice: у файла .docx в окне — «Скачать» и, для файлов версии документа, «Открыть в OnlyOffice».
- «Сейчас у: <ФИО>» в реестре (колонка «Согласование») и в карточке над маршрутом — кто должен действовать на текущем этапе. Под каждым этапом карточки — кто на нём действует; у пройденных справа — кто и когда прошёл. Если этап ждёт начальника ИБ, а отметка «Является начальником ИБ» никому не поставлена, — «Начальник ИБ не назначен»: администратору нужно поставить отметку. Цифра у «Документы» в меню — документы, где «Сейчас у» — вы.
- Задачи по этапам (с 1.6.3): кто должен действовать на этапе, получает задачу в «Задачах» (категория «Документы»). В описании — документ, тип, этап и что требуется; ссылка «Документ #…» открывает карточку, само действие (согласовать, вернуть, приложить перевод, подписанный PDF) выполняется там. Когда документ переходит дальше, задача закрывается сама. На этапе «Проверка сотрудниками» ставится одна общая задача «Проверить документ» без исполнителя: на карточке — «могут взять: …», взять её себе («Взять себе») может только человек из списка. Кто в списке — роль из «Настройки → Параметры портала → Документы: роль проверки сотрудниками» (меняет супер-администратор; не выбрана — все сотрудники ИБ). Так же одной задачей — «Отправить на подписание», когда это могут сделать несколько человек. Сроки — в «Параметры портала → Документы: сроки этапов»; на этапе ответственных лиц срок задачи — ближайший срок лица, на переводе — срок языка. Срок можно поправить в самой задаче.
- Маршрут (с 1.2.0):
  1. **Драфт** — автор правит документ, прикладывает файл документа (.docx, .pdf; «Приложить файл документа») и нажимает «Отправить на проверку сотрудникам». Файл можно приложить и на следующем этапе.
  2. **Проверка сотрудниками** — сотрудники ИБ пишут комментарии в карточке, автор отвечает там же и при необходимости заменяет файл. «На согласование начальнику ИБ» нажимает автор или его руководитель — только когда файл документа приложен.
  3. **Согласование начальника ИБ** — «Согласовать»: ничего загружать не нужно, выбран последний файл автора (можно выбрать другой) — он станет «версией при согласовании начальником ИБ». Или «Вернуть на доработку» с замечанием и, по желанию, файлом-запиской. Если файла автора нет, остаётся только возврат. Свой документ начальник ИБ не согласует, если есть другой начальник ИБ; если нет — согласует сам, и в карточке будет отметка «без независимого согласования».
  4. **Согласование с ответственными лицами** — документ рассылается по почте тем, кто должен его согласовать. В карточке — «Добавить ответственное лицо»: ФИО, подразделение или должность, срок ответа (лиц можно добавить заранее, с драфта). Начните вводить ФИО или должность — портал предложит людей из справочника «Ответственные лица»; выбор заполнит оба поля. Человека нет в списке — «Ввести вручную». Одного и того же человека (то же ФИО и та же должность) в документ дважды не добавить. Список ведёт администратор с правом «Настройки»: «Настройки → Справочники → Ответственные лица» — добавить, изменить, отключить (отключённого не предлагают при выборе; уже добавленных в документы это не меняет). Пришёл ответ — «Отметить согласование», по желанию с письмом или сканом. Срок можно перенести только с объяснением — история переносов видна в карточке. Когда согласовали все, начальник ИБ нажимает «Ознакомлен с финальной версией» и прикладывает финальную версию.
  5. **Перевод** — «Добавить язык»: язык, переводчик (ФИО или организация, по желанию), срок. Переводчик работает вне портала: готовый файл прикладывает автор документа — «Приложить перевод» на этапе «Перевод». Лишний язык можно снять, пока документ на этапе перевода или раньше. Когда у каждого языка есть файл, «На подписание» нажимает начальник ИБ или руководитель автора.
  6. **Подписание** — автор или начальник ИБ загружает подписанный PDF и дату подписания. Эта версия становится действующей.
- Вернуть на доработку — обязательно с комментарием: документ вернётся на «Драфт», автору придёт задача.
- «Добавить блокер» — если что-то мешает двигать документ (автор, его руководитель, начальник ИБ). Пока блокер открыт, документ не идёт дальше; «Снять блокер» — с пояснением.
- «Отменить пересмотр» — если новая версия не нужна: она останется в истории, действует подписанная.
- «Удалить» (право «Документы: удаление») — только документ без подписанной версии; подписанный — в архив.
- Роль «Читатель документов» — для тех, кто только читает: видны подписанные документы и их файлы. Юристы и члены правления после обновления на 1.2.0 — в этой роли.
- После подписания — пересмотр раз в 12 месяцев от даты подписания (настраивается); за 30 дней до срока владельцу ставится задача.

## Доказательства

- Доказательство привязывается к записи реестра или системе; файлы — PDF, PNG, JPG, TXT, CSV, XLSX, DOCX до 25 МБ. Файлы просматриваются прямо в карточке.
- Форма по шаблону (например, «Парольная защита»): значения проверяются по правилам шаблона.
- Проверяет другой сотрудник с правом проверки: «Принять» (со сроком действия) или «Отклонить» с комментарием — загрузившему придёт задача на исправление.

## Настройки

- **Справочники:** категории и приоритеты задач, колонки доски задач (переименовать, своя колонка на нужное место, «комментарий обязателен при переходе вперёд / при возврате»), правила разбора почты, системы и их владельцы, типы документов, получатели уведомлений (метка → сотрудники и e-mail для справки), производственный календарь РТ. Используемое значение не удаляется — только в архив.
- **Шаблоны форм** доказательств.
- **Подпись ИБ** (с 1.9.0; право «Настройки» и доступ к разделам ИБ): подпись отдела и контакт для сообщений о подозрительных письмах, RU и TJ. Письма в работе показывают новую подпись сразу, в отправленных остаётся подпись на дату отправки. Служебная учётная запись этой вкладки не видит.
- **Пользователи и роли** (администратор): создать пользователя (временный пароль показывается один раз), сбросить пароль, разблокировать, отключить, указать руководителя (сотрудник ИБ; все выше по цепочке — старшие над пользователем); матрица «Роли и права».
- **Служебная учётная запись «Администратор портала»** (с 1.8.0). Подходит для администратора, который настраивает портал, но не работает в нём.
    - Что может: заводить пользователей и назначать роли, вести справочники, шаблоны форм и производственный календарь.
    - В меню у неё только «Настройки». Задач, реестров, документов, учебных писем, поиска и журнала она не видит. Нет у неё и справочника «Ответственные лица», «Подписи ИБ», слайдов монитора, раскладок дашборда и «Параметров портала».
    - Её нельзя выбрать исполнителем, руководителем, ответственным или владельцем.
    - Роль «Администратор портала» не совмещается с другими: если отметить её в форме пользователя, остальные роли снимутся. Чтобы работать в разделах ИБ, заведите отдельного пользователя.
    - Название и права этой роли не меняются.
    - Входить можно только с рабочих мест администраторов.
- **Корзина.** Удалённые реестры, группы и типы систем уязвимостей, записи: что удалено, кто, когда, причина, сколько скрыто. Для записей уязвимостей видны статус и срок на момент удаления. Смотреть может каждый сотрудник ИБ. Восстановить может супер-администратор, только целиком — вместе со всем, что скрыло это удаление. Если название уже занято, портал попросит другое. Если тип систем снова добавили в группу или новая запись уже заняла ключ, восстановить нельзя: портал объяснит почему.
- Журнал изменений настроек — в разделе «Журнал» (фильтр «Раздел → Настройки — всё»).

## Журнал

Раздел виден пользователям с правом «Журнал действий» (по умолчанию — начальник ИБ и супер-администратор).

- Все действия пользователей: входы, изменения в разделах и настройках, выгрузки. По умолчанию — за 7 дней.
- Фильтры: период, пользователь («Система» — автоматизации и обновления), раздел, действие, IP, поиск по тексту, ФИО, логину.
- Щелчок по строке — подробности; «Открыть» — перейти к задаче, записи, документу.
- «Выгрузить в Excel» — по текущему фильтру, до 100 000 строк. Если записей больше — сузьте период.
- Историю изменений в карточках (задачи, записи, документы, доказательства) видят пользователи с правом «История в карточках».

## Если что-то не работает

- «Запрос отклонён: неизвестный источник» — портал открыт не по своему адресу: откройте его по адресу от администратора.
- «Запись изменил другой пользователь — ваши изменения не сохранены» — нажмите «Перечитать запись» и повторите правку.
- Не входит, хотя пароль верный, — возможно, вход заблокирован после 5 ошибок (подождите 15 минут) или вы входите не со своего рабочего места (для администраторов). Обратитесь к администратору портала.

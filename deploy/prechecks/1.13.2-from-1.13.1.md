Сервер работает на **1.13.1** (выложена 09.11.2026 с 1.9.0). Если там версия старше, архив собирается с `make-release.sh --from <версия>` и своими предпроверками (`deploy/prechecks/1.13.2-from-<версия>.md`).

**1.13.2 — только интерфейс (frontend):** миграций, новых переменных `.env`, изменений API и прав нет; образы db и backend по содержимому те же, что в 1.13.1 (`deploy/verification/1.13.2.md`). Шаг `migrate` по инструкции выполняется как обычно — он ничего не применяет («No pending migrations», «Seed выполнен: …»). `backup.sh` перед выкладкой — как всегда, обязательно.

### Что меняется для пользователей

- Карточки задач на доске: заголовок не наезжает на категорию и срок (до трёх строк, полностью — в подсказке), число комментариев видно целиком, инициалы исполнителя — в кружке.
- «Осведомлённость → Письма → Новое письмо»: можно сразу выбрать шаблон («Шаблон (необязательно)» → «Далее» → «Письмо из шаблона»).
- Если действующих шаблонов нет — вместо пустого списка «Шаблонов пока нет» и кнопка «Создать шаблон».

### До выкладки (на работающей 1.13.1, до `backup.sh`)

Запросов к базе нет: данные не меняются. Число записей до и после сверяет `smoke.sh`.

### После `migrate`

1. **Вывод `migrate`** — «No pending migrations to apply», «Seed выполнен: …».
2. **`./scripts/smoke.sh --after`** — «Smoke-проверка пройдена», число записей не изменилось.
3. **Вручную:** вход; «Задачи» — карточки без наложения в теме «Чёрный океан»; «Осведомлённость → Письма → Новое письмо» — есть «Шаблон (необязательно)».

### Откат на 1.13.1

Только образ frontend: `sed -i 's/^VERSION=.*/VERSION=1.13.1/' .env` и `docker compose up -d backend frontend`. Данные и база не меняются.

Сервер работает на **1.13.5** (по цепочке 1.13.3 → 1.13.4 → 1.13.5 — каждый своим архивом). Если там версия старше, архив собирается с `make-release.sh --from <версия>` и своими предпроверками.

**1.13.6 — меняются образы backend и frontend:** миграций, новых переменных `.env`, прав и seed нет; образ db по содержимому тот же, что в 1.13.5 (`deploy/verification/1.13.6.md`). **Шаг `migrate` не нужен.** Если его всё же выполнили по общей инструкции, он ничего не применяет: «No pending migrations to apply», «Seed выполнен: …». `backup.sh` перед выкладкой обязателен, как всегда.

### Что меняется для пользователей

- Справочник «Ответственные лица» — поле «Почта». В документ почта переносится вместе с ФИО и должностью.
- В карточке документа и в справочнике — кнопки «Копировать» у ФИО, должности и почты, над списком лиц — «Копировать все ФИО / должности / почты». Это для титульного листа в OnlyOffice.

### Данные

- Почта лица в документе пишется в существующую колонку `document_parties.email`. Существующие строки не меняются.
- Почты справочника — новый ключ `app_settings` `documents.partyDirectoryEmails`. Появится при первом сохранении почты.

### До выкладки (на работающей 1.13.5, до `backup.sh`)

```sql
SELECT count(*) AS parties, count(*) FILTER (WHERE email <> '') AS with_email FROM document_parties;
SELECT key FROM app_settings WHERE key LIKE 'documents.partyDirectory%';
```

Ожидается: `with_email` — только строки до 1.4.0 (обычно 0); ключ — только `documents.partyDirectory` (если справочник уже заводили).

### После выкладки

1. `docker compose ps` — backend `healthy`, frontend `Up`.
2. **`./scripts/smoke.sh --after`** — «Smoke-проверка пройдена», число записей не изменилось.
3. Те же запросы — те же числа: выкладка данные не меняет.
4. **Вручную (Chrome и Edge на Windows):** «Документы» → карточка документа с ответственными лицами → значок «Копировать» у ФИО → вставить в Блокнот: только ФИО, без пробелов и оформления. «Копировать все ФИО» → по строке на человека.

### Откат на 1.13.5

Образы backend и frontend: `sed -i 's/^VERSION=.*/VERSION=1.13.5/' .env` и `docker compose up -d backend frontend`. База не меняется. 1.13.5 справочник читает как раньше: ключ почт он не читает, но и не удаляет. Почта лиц в карточке видна текстом. После повторной выкладки 1.13.6 почты справочника на месте.

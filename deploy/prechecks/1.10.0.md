Сервер работает на **1.9.0**. Если там версия старше, сначала выложите 1.9.0 по его RELEASE.md, затем 1.10.0.

**Выкладка — обязательно с `migrate`** (шаг 5 инструкции ниже). Миграция одна, `sessions_remember`: две колонки в `sessions`. Без неё backend 1.10.0 не может открыть сессию — вход отвечает ошибкой, `smoke.sh --after` покажет «✗ сессии: колонки remember и public_id». Повторный запуск `migrate` безопасен.

### Что меняется для пользователей

- По бездействию портал больше не выходит. На форме входа — «Запомнить меня» (включено по умолчанию): сессия переживает закрытие браузера.
- Администраторы (право «Пользователи и роли», роль «Администратор портала») — сессия 12 часов от входа, «Запомнить меня» для них не действует.
- «Профиль → Мои сессии» и «Пользователи и роли» → «Сессии»: завершить сессии.
- Сессии, открытые до выкладки, доживают прежний срок (вход + 12 часов) — потом вход, уже с галочкой.
- Сроки — «Настройки → Параметры портала» → «Сессии: сроки» (только супер-администратор): `maxDays` (0 — бессрочно), `adminMaxHours` (12).

### До выкладки (на работающей 1.9.0, до `backup.sh`)

Запросы только читают базу. Результаты запишите в журнал выкладок.

```bash
docker compose exec -T db sh -c 'psql -U "$POSTGRES_USER" -d ibportal -c "
SELECT count(*) FILTER (WHERE revoked_at IS NULL AND expires_at > now()) AS открытых_сессий,
       count(*) AS строк_в_sessions
FROM sessions;
SELECT count(DISTINCT u.id) AS администраторов_12_часов FROM users u
  JOIN user_roles ur ON ur.user_id = u.id JOIN roles r ON r.id = ur.role_id
  LEFT JOIN role_permissions rp ON rp.role_id = r.id AND rp.permission_code = \$\$users.manage\$\$
  WHERE u.is_active AND (rp.role_id IS NOT NULL OR r.code = \$\$portal_admin\$\$);"'
```

- **Строк в `sessions`** — столько строк получат новые колонки (миграция переписывает таблицу; на десятках тысяч строк — секунды). Не стоп.
- **Открытых сессий** — ни одна не закроется: доживут прежний срок.
- **Администраторов** — у них после выкладки «Запомнить меня» не действует. Не стоп.

### После `migrate`

1. **Вывод `migrate`.** Применена миграция `20261105103617_sessions_remember`, «Seed выполнен: …», команда завершилась без ошибки.
2. **`./scripts/smoke.sh --after`.** Строка «✓ сессии: колонки remember и public_id (sessions_remember)», затем «Smoke-проверка пройдена». «✗ … найдено 0» — `migrate` не выполнен: повторите шаг 5.
3. **Проверка целостности.** `docker compose run --rm -T --no-deps backend node dist/scripts/check-integrity.js` → «Целостность в порядке».
4. **Вручную:** войти в портал — на форме есть «Запомнить меня»; щелчок по своему имени внизу меню → «Профиль» → «Мои сессии» показывает текущую сессию.

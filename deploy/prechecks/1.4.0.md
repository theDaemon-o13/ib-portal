### Проверяющий по задаче: что сделает шаг `migrate` (ADR-0028)

- Миграция `20261030084414_task_reviewer`: две новые пустые колонки `tasks.reviewer_id` и `task_transitions.reviewer_id`, индекс и внешние ключи. Существующие строки не меняются (0 строк).
- Seed, один раз (`tasks.reviewer.v1_4`): задачам, стоящим «На проверке» без проверяющего, ставит проверяющего — ближнего активного руководителя исполнителя с доступом к разделам ИБ. Каждой — переход и комментарий «Проверяющий назначен при обновлении на 1.4.0: <ФИО>». Задачи исполнителей без руководителя не меняются: их принимают по правилам 1.3.0.

### Проверяющий по задаче: сколько задач затронет (до выкладки)

Запрос только читает базу. Отключённые руководители пропускаются вверх по цепочке, как в seed:

```bash
docker compose exec -T db sh -c 'psql -U "$POSTGRES_USER" -d ibportal -c "
WITH RECURSIVE r AS (
  SELECT t.id AS task_id, t.number, u.manager_id AS cand, 1 AS depth
  FROM tasks t JOIN catalog_items s ON s.id = t.status_id JOIN users u ON u.id = t.assignee_id
  WHERE s.system_key = \$\$review\$\$ AND t.deleted_at IS NULL AND t.completed_at IS NULL AND u.manager_id IS NOT NULL
  UNION ALL
  SELECT r.task_id, r.number, m.manager_id, r.depth + 1 FROM r JOIN users m ON m.id = r.cand
  WHERE m.manager_id IS NOT NULL AND r.depth < 100
), ok AS (
  SELECT DISTINCT r.task_id FROM r JOIN users c ON c.id = r.cand
  WHERE c.is_active AND EXISTS (SELECT 1 FROM user_roles ur JOIN role_permissions rp ON rp.role_id = ur.role_id
                                WHERE ur.user_id = c.id AND rp.permission_code = \$\$ib.work\$\$)
)
SELECT count(*) FILTER (WHERE ok.task_id IS NOT NULL) AS получат_проверяющего,
       count(*) FILTER (WHERE ok.task_id IS NULL) AS по_правилам_1_3_0
FROM tasks t JOIN catalog_items s ON s.id = t.status_id LEFT JOIN ok ON ok.task_id = t.id
WHERE s.system_key = \$\$review\$\$ AND t.deleted_at IS NULL AND t.completed_at IS NULL AND t.assignee_id IS NOT NULL;"'
```

Числа запишите в журнал выкладок: после `migrate` в выводе должна быть строка «Задачи 1.4.0: проверяющий назначен N задачам на проверке (…); без цепочки руководителей, по правилам до 1.4.0 — M (…)» с теми же N и M.

### Проверяющий по задаче: после `migrate`

- Проверка целостности: среди строк — «задачи на проверке: проверяющий активен и не исполнитель»; если остались задачи без проверяющего — строка «· задач на проверке без проверяющего (правила до 1.4.0, tasks.review): M».

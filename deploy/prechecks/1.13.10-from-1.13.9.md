Сервер на **1.13.9**. Если там версия старше, сначала цепочка по своим архивам: 1.13.7, затем 1.13.9.

**1.13.10 — меняются образы backend и frontend, шаг `migrate` обязателен.** Миграций схемы нет, `prisma migrate deploy` ответит «No pending migrations to apply». Seed добавит методику самооценки `cyber-express-v2` и сделает её активной. Новых переменных `.env`, прав и зависимостей нет. `backup.sh` перед выкладкой обязателен, как всегда.

### Что меняется для пользователей

- «Самооценка»: в чек-листе 11-й домен «Контроль ИИ» (4 раздела) с пометкой «вне итога». Итог КБ по-прежнему из 96, по ИИ — отдельно «X из 16».
- Новая оценка создаётся на методике v2. Зафиксировать её можно при 28 из 28 разделов.
- Черновик, начатый до выкладки, остаётся на v1. В шапке есть кнопка «Обновить методику до v2».
- Зафиксированные и архивные оценки не меняются.

### Данные

- Добавляется одна строка `assessment_methodologies`.
- `is_active` у v1 — `false`, у v2 — `true`, плюс запись `assessment.methodology_activated` в журнал.
- Оценки и ответы не меняются.

### До выкладки (на работающей 1.13.9, до `backup.sh`)

```sql
SELECT code, version, is_active FROM assessment_methodologies ORDER BY version;
SELECT count(*) AS assessments FROM assessments;
SELECT count(*) AS answers FROM assessment_answers;
```

Ожидаемо: одна строка `cyber-express-v1 | 1 | t`.

### После `migrate`

1. Вывод seed — «Seed выполнен: …», без ошибок.
2. Первый запрос — две строки: `cyber-express-v1 | 1 | f` и `cyber-express-v2 | 2 | t`.
3. `assessments` и `answers` — те же числа.
4. `docker compose ps` — backend `healthy`, frontend `Up`. **`./scripts/smoke.sh --after`** — «Smoke-проверка пройдена».
5. **Вручную** (владелец роли «Самооценка»): раздел открывается, прошлые оценки показывают прежний итог из 96.

### Откат на 1.13.9

1. `docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d ibportal -c "UPDATE assessment_methodologies SET is_active = (version = 1);"'` — `UPDATE 2`.
2. `sed -i 's/^VERSION=.*/VERSION=1.13.9/' .env` и `docker compose up -d backend frontend`.

Без шага 1 версия 1.13.9 создаст новую оценку на v2 и посчитает её итог из 112. Оценки, созданные на v2 до отката, на 1.13.9 показывают итог из 112, пока не будет повторного обновления. Строка v2 остаётся в таблице (она только пополняется). Повторная выкладка 1.13.10 снова сделает её активной.

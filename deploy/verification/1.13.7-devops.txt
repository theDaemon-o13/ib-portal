                                      не войдёт ни с одного адреса — задать адрес и docker compose up -d backend)
   ./scripts/smoke.sh --after       → «Smoke-проверка пройдена», число записей не изменилось
   SQL из шага 1                    → строки перевода и языки — те же два числа; неудачных входов — не меньше
   Вручную в Chrome и в Edge на Windows, обе темы:
     - «Журнал» → действие «Неудачный вход» → у строк есть подпись причины (например, «адрес не разрешён для
       настенного монитора (MONITOR_ALLOWED_IPS)»); у логина, которого нет в портале, показаны 2 символа и длина;
     - «Настройки → Пользователи и роли» → у учётки настенного монитора либо ничего, либо чип «Монитор: адреса не
       заданы» / «Вход отклонён по адресу» с временем и адресом последнего отказа — этот адрес и есть тот, что нужно
       вписать в MONITOR_ALLOWED_IPS (если он не совпадает со шлюзом Docker или адресом nginx — иначе теряется адрес
       клиента, см. docs/runbook/deploy.md, раздел 10);

   Ничего не сохранять. Если что-то не так — снимок экрана разработчику (выкладку не откатывать, если данные в порядке).
